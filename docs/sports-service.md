# 운동한칸

기존 공개 데이터 아틀라스의 다섯 번째 서비스. `/services/sports/` 및 `/api/sports`.

## 실제 자료와 범위

- 전국공공시설개방정보표준데이터: https://www.data.go.kr/data/15013117/standard.do
- 2026-10-27 UTC에 키 없이 공개 HTML 표 499행을 확인하고 체육시설 유형에 해당하는 203개 고유 시설을 선별했습니다. 경기도·경상남도·충청남도·서울특별시·충청북도·인천광역시·세종특별자치시·대전광역시 일부입니다. 전국 전체 목록이 아닙니다. 개별 자료 기준일 2026-08-30~2026-10-14. 수집 시각과 원본 HTML SHA256을 `public/sports-snapshot.json`에 기록했습니다. `scripts/snapshot_sports.py`로 재현할 수 있습니다. 가상 예시 없음.
- 실제 12,051 API 목록에 있는 충청남도 계룡시_공공체육시설현황 API (15096026): https://www.data.go.kr/data/15096026/openapi.do
- 공식 명세의 HTTPS 요청: `https://apis.data.go.kr/5580000/publicPhstrnFcltySttusService/getpublicPhstrnFcltySttus`. `serviceKey`, `currentPage`, `perPage`를 사용하며 최대 20행만 요청합니다. 공식 설명의 원자료 기준은 2021-09-01입니다. 지금 API에서 조회해도 현재 개방·예약·빈자리·운영시간을 보장하지 않습니다. 원문 필드 FCLTY_NM/LOCPLC_RDNMADR/LOCPLC_LNM_ADRES/RESVE_MTH/FCLTY_STTUS만 표시하고 미제공 요금·시간은 추정하지 않습니다.

공개표와 API는 별도 탭으로 분리하며 합산·중복추정하지 않습니다. 사용료·사용기준시간은 복합 문자열과 0을 그대로 보여 주며 계산하지 않습니다. 무료 구분은 자료 기준일의 원문입니다. 현재 이용 조건은 관리기관과 공식 홈페이지를 확인하도록 안내합니다. HTTP 홈페이지는 자동 HTTPS 변환 없이 링크를 생략하고 공식 포털 원문 링크를 제공합니다.

## 인증 및 실패 처리

기존 운영 `DATA_GO_KR_SERVICE_KEY` fallback, 선택적인 기존 호환용 `SPORTS_GYERYONG_KEY` override 지원. 별도 키 생성·등록·복사·권한 변경 없음. 공공데이터포털 공통키 사용과 개별 서비스 활용승인은 별개입니다. 승인 오류 시 사용자가 공식 상세 페이지에서 해당 서비스 활용승인 상태를 확인해야 하며 앱은 신청하지 않습니다. 서울 별도 인증은 이 서비스에 사용하지 않습니다.

요청 제한 10초, 브라우저 제한 12초, 성공 결과 최대 15분 서버 캐시. 리디렉션은 차단하고 2MiB 제한·JSON/XML 방어·비밀 반사 차단·정형 오류만 반환합니다. 원문 인증 URL·오류 메시지는 클라이언트로 보내지 않습니다. 키 없음·승인/인증 오류·형식 오류·빈 결과·네트워크 실패를 분리하고 공개표는 계속 사용할 수 있습니다. API는 사용자 버튼으로만 조회합니다. 검색 쿼리가 있는 서버 요청은 인증 호출 전에 400으로 거절합니다.

## 개인정보 및 사용성

위치 권한·가입·예약·연락처 입력 없음. 지역·종목·요금 필터와 검색은 브라우저 메모리에서만 처리하며 localStorage/서버에 저장하지 않습니다. 초기화, 더 보기, 키보드 상세 열기/Escape 닫기/포커스 복원, 모바일 대응과 상태 메시지를 제공합니다. 외부 링크는 HTTPS·무인증 URL만 허용합니다. 기관 텍스트는 React 기본 이스케이프로 렌더링합니다.

## 검증

최종 테스트와 실제 배포 검증 결과는 이번 작업 종료 보고에 기록합니다. 단위·계약 검증은 정적 공개표·입력·링크 보안·응답 형식·공통키 우선순위·누락 키·오류·반사·캐시·검색조건 미전송을 포함합니다. 브라우저 검증은 기존 서비스 회귀와 새 서비스 검색·필터·초기화·빈 결과·오류·모바일·키보드·개인정보 미저장을 포함합니다.
