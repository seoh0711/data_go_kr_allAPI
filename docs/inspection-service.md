# 검사소 문의노트

[운영 경로](https://data-go-kr-api-atlas.pages.dev/services/inspection/)는 검사소 두 후보의 공개 검사 항목·시간·연락처를 비교하고,원문 선택근거를 남겨 문의 준비서를 만드는 서비스입니다. 주차/출근 탐색과 다른 문제이며 검사 의무·기한·종류·법적 자격·개인 차량 적합성·현재 접수·예약/검사비를 판단하지 않습니다.

## 실제 공개표 범위

[전국자동차검사소표준데이터15021107](https://www.data.go.kr/data/15021107/standard.do)의 공식 HTML을 **2026-10-31 02:37 UTC,HTTP200**으로 직접 수집했습니다. 공개표 일부 **499행→499기록**,기준일 **2026-01-13~2026-08-30**,유형 원문은 이번 표본 모두 **민간**입니다. 전국 전체/고유 검사소499곳·현재 등록/영업/접수 상태·공공검사소만의 목록으로 단정하지 않습니다. 이전503 기록은 보존하며 이번 한 공개표 정상 응답이 모든 기관 복구를 뜻하지 않습니다.

`scripts/snapshot_inspection.py --html <직접 확보한 공식 HTML 경로>`로 재현합니다. `public/inspection-stations.json`에 수집시각·원문 해시·범위·기준일·지역/유형 분포를 기록했습니다. 보존한 필드는 명칭·유형·주소·공개전화·운영시간·검사 표기7항목·관리기관/전화·기준일입니다. 좌표·면적/진로/인력 수·개인 차량/소유자·사진/건강정보를 보존하지 않습니다. 보존 필드 완전 중복만 합치며 이번에는499행이 모두 남았습니다. 유형 범위가 달라지면 추출기를 중단해 현재 ‘모두민간’ 표시를 허위로 갱신하지 않습니다.

신규/정기/튜닝/임시/수리/배출가스정밀/택시미터검정 표기Y/N/빈값은 원문입니다. Y를 현재 접수·검사능력 인증·내 차량 의무/검사종류 판정으로 바꾸지 않습니다. 지역 원문·검사항목/표기값·공개정보 검색을 제공하며 원문 지역의 오기 ‘충청남동’도 임의 정규화하지 않습니다. 현재 관할/근거리·동선·대기시간·검사료를 추정하지 않습니다.

전화 형식 검사는 기본 국내 번호 형태와 전부0인 원문을 구분하는 표시용 검사입니다. 실제 통화/소유자를 검증하지 않습니다. 원문 `000-0000-0000`은 보존하되 통화 링크/전화 선택근거로 쓰지 않고 형식 확인 필요로 표시합니다. 형식이 통과한 번호도 현재 연결을 보장하지 않습니다.

## 원문 선택근거와 교체

두 후보의 명칭/주소·공개전화·날짜/공식출처·시간·검사 표기/현재확인한계5그룹을 비교합니다. 먼저 문의할 후보를 직접 고르고 공개 주소·시간·전화·정기검사Y 표기 중 읽은 원문 항목을 선택 이유로 남깁니다. 추천 점수·개인 적합성이 아닙니다. 선택근거는 **기록ID·기준일·원문값**과 묶이고 그 후보/현재 원문과 일치해야 준비서를 만들 수 있습니다. 문의 후보/근거를 바꾸면 과거 검토/문구를 무효화합니다. 3검토는 문구를 읽었다는 표시이며 실제 기관 확인/이해·문의 성공을 증명하지 않습니다.

두 후보가 있을 때 다른 기록을 고르면 교체 대상과 전후5그룹·선택근거 영향을 먼저 보여 줍니다. 확정 전에는 현재 준비를 유지합니다. 문의 후보를 교체하면 기존 근거와 문의 후보를 해제하고 새로 선택하게 합니다. 새 후보의 같은 항목이000/미제공이라면 그 원문과 선택 제한 이유를 표시합니다. 다른 비교 후보만 교체하는 경우 기존 문의 후보의 근거는 유지하지만 비교가 바뀌므로 검토/문구는 다시 만듭니다. 취소는 기존 선택/근거/검토/문구를 그대로 보존합니다.

같은 공개표 판본에서 마지막1회 변경을 되돌릴 수 있으며 원래 선택근거·검토/준비 문구도 정확히 복구합니다. 새로고침/자료 재수신/새 판본에서는 이전 준비를 보관하지 않습니다. 검토 중 충돌 조작을 제한하고 제목/취소 원래 버튼의 초점 복귀를 제공합니다. 없는 원문을 새 후보의 선택 이유로 이어 붙이지 않습니다.

## 기존 API 조합·설정과 공식 문서 확인

12,051건 실제 목록의 기존 세 연결을 `/api/benefits`에서 재사용합니다. 제목·요약·기관명에 차량/자동차/교통 문구가 있는 안내를 독립적으로 찾습니다. 선택 검사소의 제휴·검사비 지원·개인 자격으로 매칭하지 않습니다. 각 첫최대100건·성공 캐시 최대30분,화면 첫100건 범위이며 빈 결과는 전체 제도 부재가 아닙니다.

|---|---|---|
|[대한민국 공공서비스(혜택) 정보15113968](https://www.data.go.kr/data/15113968/openapi.do)|`https://api.odcloud.kr/api/gov24/v3/serviceList`|JSON 첫100건|

공통 `DATA_GO_KR_SERVICE_KEY` fallback,기존 `BENEFITS_GOV24_KEY`/`BENEFITS_CENTRAL_KEY`/`BENEFITS_LOCAL_KEY` override를 유지합니다. 공통 키 사용과 각 서비스 활용승인은 별개이며 오류 시 해당 공식 서비스의 기존 승인/운영 적용을 확인해야 합니다. 이번에 키 생성·등록/복사·권한·지속 접근·서버 어댑터를 변경하지 않습니다. 클라이언트로 키를 보내지 않습니다.

이번 공식 문서 재확인에서 정부/중앙 상세 페이지는각503,지자체는200으로 서비스 제목·기존 기관 경로/목록 오퍼레이션 포함을 확인했습니다. 전체 최신 명세/활용신청 조건·개인 승인 상태는 재검증하지 못했습니다. [상태 요약](improvements/evidence/005-official-docs.json). 문서 접근과 실제 운영 응답 검증을 구분해 미연결/빈/부분 실패·수신/수정시각을 표시합니다. 카탈로그15057736 검사정보 서비스의 상세 권한/요건·최신 명세는 미검증이며 새 연결/차량정보 조회를 하지 않습니다. 서울/계룡/분리배출 등 보류API도 재호출하지 않습니다.

## 개인정보·outcome 한계

차량번호/차대번호·소유자/연료/차종·검사기한/일정·개인 위치/건강·개인 연락처를 받지 않습니다. 검색/선택·원문 근거/검토·교체/복구·준비 문구는 화면 메모리에만 두고 URL/서버/브라우저 저장소·외부 추적으로 보내지 않습니다. 자유 메모/키 입력 칸이 없고 준비 문구는 읽기 전용·기본 복사 기능만 제공합니다. 실제 전화·예약/검사·법률/차량 적합성 판단을 수행하지 않습니다.

직전 두곳방문 노트와 주차돋보기를 실제 측정하고 구현 전 목표를 고정했습니다. [회차005 기준선→목표→관측·테스트/배포](improvements/005-inspection.md)를 확인하세요. 자동화 대리 과업 통과는 실제 문의/검사 성공·사용자 이해/만족·시간절감의 증거가 아니며 해당 실사용자 outcome은 미측정입니다.

운영 문구 점검에서 ‘검사’ 단독 어휘5건은 차량 어휘가 없어 범용 검사 안내가 혼입될 수 있음을 확인했습니다. 단독 ‘검사’를 제외하고 차량/자동차/교통 어휘만 표시하도록 좁혔습니다. 이는 실제 차량/검사소 제휴·자격 판정이 아니라 공개 문구 필터이며 핵심 선택근거 과업의 목표/입력은 바꾸지 않았습니다.
