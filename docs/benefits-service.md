# 혜택모아 — 구현 및 검증 범위

> 운영 상태 갱신: 사용자가 공통 키를 직접 등록했고 실제 API 수신을 확인했습니다. 아래의 초기 미등록/미검증 기록과 현재 상태는 [최신 연결 검증](live-connection-verification.md)을 구분해 보세요.

배포 위치: 기존 데이터 아틀라스의 `/services/benefits/`. 출근나침반의 코드와 경로는 보존합니다. 새로운 호스팅 프로젝트, 계정, 유료 서비스, 접근 권한, 예약 작업은 만들지 않습니다.

## 사용 흐름

1. **공식 안내**: 공공데이터포털 공개 목록에 있는 안내 자료의 설명 8건을 표시합니다. `public/benefits-guides.json`은 기존 12,051건 공식 스냅샷에서 설명을 그대로 발췌했습니다. 현재 신청 가능한 개별 지원 제도 목록이 아님을 상시 표시합니다.
2. **연결된 제도**: 승인된 각 API를 서버에서 조회합니다. 기관별 첫 100건 이내만 포함하고 전체 목록으로 표시하지 않습니다. 현재 Cloudflare 운영 서버에는 공통 키가 등록되지 않아 연결 대기 상태입니다. 연결 실패를 예시로 대체하지 않습니다.
3. **예시 체험**: 명백히 가상인 다섯 항목으로 탐색·관심목록을 체험합니다. 실제 제도명, 금액, 기한, 신청 링크를 꾸며 넣지 않습니다.

검색·지역·관심 연령대·주제·관심목록은 브라우저 메모리에서만 처리합니다. 숫자 나이, 주민등록번호, 소득, 건강 정보, 아동 정보는 입력받지 않습니다. 선택 조건을 서버·URL·브라우저 저장소에 저장하거나 전송하지 않습니다. 연령대는 이용자 본인의 신상 정보가 아닌 **관심 주제**입니다. 초기화는 모든 탐색 조건을 해제하며, 새로고침하면 관심목록도 지워집니다. 지역·연령이 알려지지 않은 항목을 임의로 제외하거나 수급 자격을 판정하지 않습니다.

## 공식 명세 확인

2026-10-26 공식 포털 상세 페이지를 직접 열어 서비스명·형식·승인 조건을 확인했습니다. 복지로 두 서비스는 페이지에 포함된 Swagger 명세의 경로·필수 파라미터·응답 필드도 확인했습니다. 정부24 외부 Swagger 호스트는 현재 환경 허용 목록 밖이므로 접근하지 않았으며, 포털 페이지와 공식 `open-data-list` 수집본의 `serviceList` 기능·필드를 대조했습니다.

- 세 서비스 모두 포털에 무료로 표시되어 있습니다. 비용을 발생시키는 상품·가입을 추가하지 않습니다.
- 초기 인증 없는 조회는 HTTP 401이었습니다. 이후 사용자가 공통 키 사용을 확인한 뒤, 이미 허용된 `api.odcloud.kr`에 현재 `DATA_GO_KR_SERVICE_KEY`로 1건만 조회하여 HTTP 200, 실제 데이터 1건, 전체 10,957건, 서비스 ID·제목·수정시각 존재를 확인했습니다. 원문·키·인증 URL은 출력하거나 파일에 저장하지 않았습니다.
- 세 서비스 모두 `DATA_GO_KR_SERVICE_KEY` 하나를 기본으로 사용할 수 있습니다. 같은 인증키 사용과 서비스별 활용 승인은 별개입니다. 기존 기관별 변수는 선택적인 우선 설정이며, 서로 다른 키를 발급받아야 한다는 의미가 아닙니다.
- 중앙부처 목록은 `callTp=L`, `srchKeyCode=003`, `pageNo=1`, `numOfRows=100`; 지자체는 `pageNo=1`, `numOfRows=100`; 정부24는 `page=1`, `perPage=100`, `returnType=JSON`입니다.
- 운영자가 Cloudflare Pages 프로젝트 `data-go-kr-api-atlas`의 production **Secrets**에 `DATA_GO_KR_SERVICE_KEY` 하나를 등록하고 재배포하면 세 서비스가 공유합니다. 표의 기관별 우선 설정도 호환성을 유지합니다. 디코딩 키를 사용합니다. Codex 환경에서 Cloudflare로 자동 전달되지 않으며, 이 작업에서는 키 생성·등록·복사·권한 변경을 수행하지 않았습니다.
- 현재 실행 환경은 `api.odcloud.kr`만 공통 키 사용 대상으로 허용합니다. `apis.data.go.kr`의 복지로 2종은 네트워크 허용 대상과 키 사용 대상 밖이어서 인증 호출을 하지 않았으며 승인 여부도 미확인입니다. 접근 제한을 우회하지 않았습니다.

## 조회·오류·보안

자동 반복 조회를 하지 않으며, 첫 진입과 명시적 다시 조회만 지원합니다. 제공기관 트래픽을 줄이기 위해 기관별 정규화된 공개 결과를 Cloudflare Cache API에 30분 저장하며, `/api/benefits` 응답은 5분 캐시될 수 있습니다. 각 기관의 실제 수신 시각을 KST로 구분해 표시합니다. 개인 검색 조건은 캐시 키에 포함되지 않습니다.

기관별 `needs_key`, `live`, `empty`, `error`를 구분합니다. 하나의 장애가 나머지 결과를 없애지 않습니다. 빈 응답은 오류로 취급하지 않으며, 비정상 스키마는 오류로 처리합니다. 응답 크기 2 MiB 제한, 10초 타임아웃, 고정된 제공기관 호스트, 리디렉션 금지, XML DOCTYPE/ENTITY 금지, 공식 HTTPS 링크 검증을 적용했습니다. HTML 설명은 React 텍스트로 표시합니다. 응답은 공개 제도 필드만 선택하며, 반사된 인증키를 포함하는 결과는 폐기합니다. 원본 응답·인증 URL·비밀값을 로그에 기록하지 않습니다.

## 검증과 한계

- 단위/계약 테스트: 공개 설명과 원본 일치, 검색·필터·잘못된 입력, 미연결 시 외부 요청 없음, 정부24 JSON·복지로 XML, XML 공격·과대 응답·오류 스키마, 부분 장애·빈 응답, 캐시, 비밀값 미노출, 공식 URL 검증.
- 브라우저 테스트: 아틀라스 진입 링크, 공식 안내/실제 조회/체험 분리, 검색·필터·관심목록·초기화·모달, 네트워크 실패·재시도, 데이터 누락·부분 실패, 개인정보 미저장·미전송, KST 시각, 모바일 폭, 기존 아틀라스와 출근나침반 회귀.
- 정부24의 실제 1건 응답은 환경의 기존 공통 키로 확인했습니다. 배포 서버는 공통 키 미등록 상태이므로 운영 연결 성공을 뜻하지 않습니다. 복지로 2종의 인증된 제도 내용과 기관별 운영 한도는 접근 허용 후 검증해야 합니다. 자동 테스트의 기관 응답은 명시적인 모의 응답이며 실제 제도 수신 검증으로 간주하지 않습니다.
