# 마을체험 문의순서

운영 경로 `/services/villages/`. 두 농어촌체험휴양마을의 공개 프로그램/시설 원문을 비교하고 **미확인 질문2개 중 먼저 물을 질문1개를 명시한 문의 준비서**를 만듭니다. 실제 문의·예약·현재 운영/시설·이용자 자격 판단은 하지 않습니다. 농기계 임대·정규 강좌 탐색과 다른 마을체험 사전문의 과업입니다.

## 공식 공개자료와 범위

[전국농어촌체험휴양마을표준데이터15013113](https://www.data.go.kr/data/15013113/standard.do)를2026-10-31 14:40 UTC에 HTTP200으로 확인했습니다. 공개표499행→499기록·11지역의 일부이며 기준일은 모두2026-09-22입니다. 전국 전체·현재 체험운영/시설·예약 가능·가격·개인 자격을 뜻하지 않습니다. 지역 명칭·프로그램 구분/명칭은 원문 그대로 둡니다.

이번 표본은 프로그램명499건 기재·보유시설499건 빈값입니다. 빈값을 시설 없음으로 만들지 않습니다. 프로그램 기재도 현재 운영·일정·참여조건·예약 가능을 뜻하지 않습니다. 원문에서 체험마을명·지역·프로그램 구분/명칭·시설정보·주소·관리기관·기준일만 보존합니다. 대표자명/대표전화·사진/홈페이지·좌표/면적은 제외했습니다. 원문 응답의 임시 파일도 추출/해시 검증 후 폐기하고 검증 해시/공개시설 JSON만 남깁니다.

`public/villages.json`은 수집일·기준일·범위·원문SHA256을 포함한 고정 스냅샷입니다. 추출기는 공식 표의 스키마/열수/필수값/행수 검증이 실패하면 기존 자료를 바꾸지 않습니다.

## 과업과 복구

2후보×5정보그룹·원문 선택근거(기록ID/기준일/값)를 유지합니다. 프로그램 운영·시설·관리기관 중 아직 확인하지 못한 질문2개를 원문/기록/날짜에 연결합니다. 그중 먼저 물을 질문1개를 직접 고르고 검토3개 후 준비합니다. 우선질문은 선택한 두 질문 중 하나여야 하며 질문키와 현재 원문 기록/시점/값을 통해 연결됩니다. 준비 문구에는 우선질문과 그 원문을 먼저 표시하고 질문 목록도 해당 순서로 만듭니다. 질문2개/검토3개만 있고 우선질문이 없으면 준비하지 않습니다.

후보 교체 전 5그룹·질문2쌍·원문 선택근거에 더해 우선질문의 전후 원문과 순서 초기화 이유를 보여줍니다. 취소는 기존 준비/질문/순서를 보존합니다. 확정은 질문/우선순서·검토/문구를 해제하고 문의 후보가 바뀌면 선택근거도 해제합니다. 새 원문에 맞춰 다시 골라야 합니다. 질문 집합이나 우선순서를 바꿔도 검토/문구를 무효화합니다. 같은 판본의 마지막1회 변경만 되돌리고 새로고침/자료 재수신/새판본에서는 복구하지 않습니다.

모바일·키보드 라디오/체크박스·초점 복귀·검색/지역/기재/미제공 필터·초기화·빈 결과·더보기를 제공합니다. 공개표 실패는 재조회하고 독립 공공안내의 미연결/빈/부분실패/형식오류는 선택·질문/순서·준비와 구분합니다. 확인/검토 표시는 실제 이해/문의/기관 답변이 아닙니다.

## API 조합과 비밀값 없는 연결 안내

12,051건 API 목록의 기존3기관 `/api/benefits`를 재사용합니다. 제목/요약/기관명의 농촌/체험 문구를 찾는 별도 안내이며 선택한 마을·이용자 자격/지원금과 매칭하지 않습니다. 각 첫최대100건·성공 캐시 최대30분·화면 첫100건 범위이며 빈 결과는 전체 제도 부재가 아닙니다. 실제 수신 상태/기관시각을 표시합니다.

|기존 공식 서비스|보존한 HTTPS 경로|
|---|---|
|[행정안전부 대한민국 공공서비스(혜택)15113968](https://www.data.go.kr/data/15113968/openapi.do)|`https://api.odcloud.kr/api/gov24/v3/serviceList`|
|[중앙부처복지서비스15090532](https://www.data.go.kr/data/15090532/openapi.do)|`https://apis.data.go.kr/B554287/NationalWelfareInformationsV001/NationalWelfarelistV001`|
|[지자체복지서비스15108347](https://www.data.go.kr/data/15108347/openapi.do)|`https://apis.data.go.kr/B554287/LocalGovernmentWelfareInformations/LcgvWelfarelist`|

공통 `DATA_GO_KR_SERVICE_KEY` fallback과 기존 `BENEFITS_GOV24_KEY`/`BENEFITS_CENTRAL_KEY`/`BENEFITS_LOCAL_KEY` override를 유지합니다. 공통 키 사용과 개별 서비스 활용승인은 별개입니다. 신규 키/Secrets 등록·복사·권한·지속 접근·서버 변경은 없습니다. 오류 시 공식 활용승인/운영 적용을 확인하되 키를 채팅/URL/브라우저/공개파일에 넣지 마세요.

이번 정부 혜택 상세 문서는503,중앙/지자체는200이었습니다. 최신 전체명세/개인 활용승인 상태는 미검증이며 실제 운영 응답과 구분합니다. [의령군 농어촌체험마을 서비스15112087](https://www.data.go.kr/data/15112087/openapi.do)는200으로 공식 HTTPS 경로 `https://apis.data.go.kr/5390000/uiryeongcdvilex/getUiryeongvilexListNew`를 확인했으나 **미연결**입니다. 공통키 호환·개인 승인·실제 호출은 검증하지 않았습니다. 새 연결이 필요하면 공식 활용신청/HTTPS 명세·승인 상태 확인이 선행돼야 하며 이번에 등록/인증 호출하지 않습니다.

자전거/무인민원 표준 페이지는 외부 다운로드 전환 상태여서 새 호스트 접근/설정을 추가하지 않았습니다. 휴양림/견인 검색503·기존 서울HTTPS/계룡/분리배출 보류도 우회/불필요한 재호출하지 않았습니다.

## 개인정보와 검증 한계

개인/가족·아동 정보·건강·방문 경로·위치·연락처를 입력받지 않습니다. 검색/선택·원문 근거/질문·우선순서·검토·복구·준비 문구는 화면 메모리에만 두고 URL/서버/브라우저 저장소·외부 분석으로 보내지 않습니다. 준비 문구는 읽기 전용이며 브라우저 기본 복사 기능만 사용할 수 있습니다. 기관에 연락/예약하지 않습니다.
