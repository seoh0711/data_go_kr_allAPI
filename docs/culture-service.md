# 문화쉼표

> 운영 상태 갱신: 사용자가 공통 키를 직접 등록했고 실제 API 수신을 확인했습니다. 아래의 초기 미등록/미검증 기록과 현재 상태는 [최신 연결 검증](live-connection-verification.md)을 구분해 보세요.

기존 데이터 아틀라스의 `/services/culture/`에 추가한 세 번째 생활 서비스입니다. 도서관 방문 후보를 고르는 데 집중하며, 출근나침반·혜택모아를 보존합니다. 새 프로젝트·계정·접근 권한·키·예약·유료 서비스를 만들지 않습니다.

## 키 없이 제공하는 실제 기능

공식 [전국도서관표준데이터](https://www.data.go.kr/data/15013109/standard.do) 상세 페이지의 공개 HTML 표에서 **실제 도서관 499건**을 수집했습니다. 기관의 이름, 원문 지역·주소, 전화·홈페이지, 휴관일, 평일·토요일·공휴일 시간표, 데이터 기준일만 선택했습니다. 담당자·개인 이용자·좌석 이용자·개인 위치 정보는 수집하지 않았습니다.

- 2026-10-26 수집. 정확한 UTC 수집 시각과 공개 HTML의 SHA-256은 `public/culture-libraries.json` 메타데이터에 있습니다.
- 원문 데이터 기준일 범위: **2026-01-13 ~ 2026-09-28**.
- 14개 **원문 표기 지역**, 499개 고유 시설. 전국 전체 도서관 목록이 아닙니다. 원문 지역명은 임의로 변경하거나 현재 행정구역으로 재분류하지 않습니다.
- 이 자료는 고정 스냅샷이며, 실시간 개관·잔여 좌석·임시 휴관·현재 이용 조건을 뜻하지 않습니다.
- 평일 18시 이후 종료, 토요일 시간 등록 필터는 등록된 시간표만 사용합니다. 휴관일·공휴일을 반영한 개관 여부 계산을 하지 않습니다. `00:00–00:00`이나 결측 시간은 ‘시간표 확인 필요’입니다. 공휴일 시간을 일요일 시간으로 대체하지 않습니다.
- 원문에 이용료가 없어 **무료 판정·무료 필터를 제공하지 않습니다**. 기관별 회원 자격, 입주민 한정 여부, 대출 비용·예약·회비는 원문 홈페이지나 전화로 확인해야 합니다.
- 검색·지역·종류·시간표·가나다순/원문순·방문 후보·상세 안내·전화/원문 홈페이지 연결을 제공합니다. 방문 후보와 조건은 브라우저 메모리에서만 사용하며 새로고침 시 초기화됩니다.

수집기는 공개표의 26개 열 구조·500건 이하·필수 필드·중복을 확인하고 성공할 때만 기존 JSON을 교체합니다. 인증키나 쿠키를 사용하지 않습니다.

```sh
python3 scripts/snapshot_culture.py
# 동일한 공개 HTML 캡처로 재현할 때
python3 scripts/snapshot_culture.py --html /absolute/path/to/public-page.html
```

수집 HTML은 체크아웃 밖 `/workspace/culture-research/libraries.html`에 보관했습니다. 이 파일은 공개 배포에 포함하지 않습니다. 공개 JSON에는 필요한 시설 정보만 들어갑니다. 자동 주기 갱신은 하지 않습니다.

## 아틀라스 12,051개 중 조합한 API 두 개

2026-10-26 공식 포털 페이지와 포함된 Swagger 명세를 직접 읽어 경로·형식·필수 인수·응답 필드를 확인했습니다. 두 API 모두 포털에 무료·이용허락범위 제한 없음·개발/운영 자동승인으로 표시됩니다. 이용료의 무료 표시는 **API 사용 비용**이며, 문화시설 입장료를 뜻하지 않습니다.

| API | 이 서비스에서 쓰는 목록 경로 | 필수 요청값 | 비밀값 |
| --- | --- | --- | --- |
| [15138930 한국문화정보원_문화시설조회서비스](https://www.data.go.kr/data/15138930/openapi.do) | `https://apis.data.go.kr/B553457/nopenapi/rest/cultureartspaces/library` | `serviceKey`, `PageNo=1`, `numOfrows=20` | 공통 `DATA_GO_KR_SERVICE_KEY`; 선택 우선 설정 `CULTURE_PLACES_KEY` |
| [15138937 한국문화정보원_한눈에보는문화정보조회서비스](https://www.data.go.kr/data/15138937/openapi.do) | `https://apis.data.go.kr/B553457/cultureinfo/period2` | `serviceKey`, `PageNo=1`, `numOfrows=20`; 한국 표준시 오늘부터 30일 `from/to` | 공통 `DATA_GO_KR_SERVICE_KEY`; 선택 우선 설정 `CULTURE_EVENTS_KEY` |

두 서비스는 공공데이터포털 공통 키를 사용합니다. 별도 발급 체계의 서울 열린데이터광장 키 등은 사용하지 않습니다. 같은 키 사용과 각 서비스의 활용 승인은 별개입니다. 기존 공통 키 선택 헬퍼를 그대로 재사용했습니다.

문화시설 목록의 공식 헤더 `reseultCode` 오탈자와 정상 `resultCode`를 모두 처리합니다. 문화시설 목록은 시설명·분류·전화·홈페이지를, 문화행사는 제목·지역·장소·시작/종료일을 제공합니다. 목록에 없는 주소·운영시간·이용료·개별 원문 URL은 생성하지 않습니다. API 탭은 공개표와 별도이며, 이름 유사성만으로 서로 다른 시설을 결합하지 않습니다. 고정 도서관 자료와 API 자료의 중복 시설 수를 전체 시설 수로 합산하지 않습니다.

공식 API 인증 호출은 **이번 실행에서 하지 않았습니다.** 현재 실행 환경은 `apis.data.go.kr`를 네트워크/키 사용 대상으로 허용하지 않고, Cloudflare 운영 공통 키는 사용자 수동 등록 대기입니다. 기존 키 전달 차단을 재시도하거나 다른 호스트로 우회하지 않았습니다. 운영 키 등록·권한 변경·별도 키 생성은 이 작업 범위 밖입니다. 사용자가 운영 Secrets에 공통 키를 등록한 뒤 재배포하면 API 조회가 가능하며, 서비스별 승인과 실제 기관 응답은 그 후 확인해야 합니다.

## 서버·개인정보·오류 처리

`functions/api/culture.js`의 `/api/culture`는 두 기관별 조회 상태를 반환합니다. 기본 도서관 화면은 API를 호출하지 않습니다. API 탭 최초 진입과 ‘다시 조회’만 요청하고 자동 반복 조회하지 않습니다. 기관별 성공/빈 응답은 1시간, 전체 응답은 5분 캐시될 수 있습니다. 기관별 실제 수신 시각을 KST로 표시하고, 스냅샷 수집 시각·자료 기준일과 구분합니다.

검색어·관심 지역·방문 후보는 서버로 보내지 않습니다. `/api/culture`의 쿼리 인수는 모두 400으로 거절하며, 위경도 검색 인수도 제공기관에 보내지 않습니다. 위치 권한을 요청하지 않고 지도·외부 썸네일·추적 이미지를 자동 로드하지 않습니다. 기관 홈페이지·전화는 명시적 사용자 클릭 시에만 열립니다.

`needs_key`·`live`·`empty`·`error`를 기관별로 구분하고, 부분 장애가 정상 자료를 없애지 않게 했습니다. 예시/가상 시설은 제공하지 않습니다. 응답 크기 2 MiB, 10초 타임아웃, 고정 제공기관 호스트, 리디렉션 금지, XML DOCTYPE/ENTITY 금지, 정규화 필드 선택, 반사된 인증키 폐기, 연락처 URL 검증을 적용했습니다. API 원문·인증 URL·비밀값을 출력하거나 로그에 남기지 않습니다.

## 검증 범위

- 실제 공개표 499건·고유 ID·기준일·일부 목록 표시·이용료 미추정 검증.
- 검색/필터/후보/초기화/정렬/더 보기, 빈 결과, 손상된 공개 자료, 긴 입력 제한 검증.
- API 공통 키 및 선택 우선 설정, KST 기간·연도 경계, 공식 XML 스키마, 부분 실패, 빈 응답, 캐시, 과대 응답, XML 공격, 비밀값 반사 방지 검증.
- 브라우저에서 데스크톱/390px 모바일/키보드 모달/원문 링크/입력 미전송·미저장/위치 권한 미요청 확인.
- 기존 아틀라스·출근나침반·혜택모아 회귀 검증.
- 자동 테스트의 제공기관 응답은 모의 응답입니다. 실제 API의 인증된 운영 데이터 검증을 대체하지 않습니다.
