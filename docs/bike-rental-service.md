# 자전거대여 문의카드

운영 경로 `/services/bike-rental/`. 두 대여소의 공개 조건을 비교하고 **질문2개·우선질문과 공개 문의경로를 원문에 묶은 준비 카드**를 만듭니다. 현재 영업·빌릴 수 있는 자전거 수량·적용 요금·예약·개인 자격을 판단하거나 실제 통화/예약을 수행하지 않습니다.

## 공식 자료와 해석 범위

[전국자전거대여소표준데이터15017319](https://www.data.go.kr/data/15017319/standard.do)를2026-10-31 20:31 UTC에 HTTP200으로 확인했습니다. 공개표499행→499기록·지역 원문16종의 일부이며 기준일2024-01-30~2026-09-03입니다. 전국 전체/현재 대여현황이 아닙니다. 과거/현재 지역 명칭과 전화/요금/시간의 원문을 임의 정규화하지 않습니다.

보존 필드는 대여소명/구분·주소·시간/휴무·요금구분/내용·보유대수/거치대수·공기주입기/수리대 표기·관리기관/공개 관리전화·기준일입니다. 좌표·개인 위치·이용자 정보/이력은 제외합니다. `public/bike-rental.json`은 범위/수집일/기준일/원문SHA256을 가진 고정 스냅샷입니다. 추출기는 공식 스키마/열수/필수값/행수 검증 실패 시 기존 파일을 바꾸지 않습니다.

보유69대라는 원문을 현재 빌릴 수 있는69대로 바꾸지 않습니다. 무료/유료·요금 문구가 현재 적용되는지·이용 단위/대상은 기관 확인이 필요합니다. 시간/휴무·우천 문구로 지금 영업 중이라고 판단하지 않으며 이동시간/가까움/예약 가능을 계산하지 않습니다. 편의시설Y/N과 빈값도 기준일 원문입니다.

## 질문과 공개 문의경로

2후보×5그룹 비교,기록ID·기준일·원문값에 묶은 선택근거,미확인 질문2개와 우선질문1개를 유지합니다. 그 우선질문을 확인할 **공개 관리전화 또는 공식 원문에서 기관 안내 확인** 경로를 직접 고릅니다. 문의경로는 기록ID/기준일/기관/경로종류/원문값과 우선질문키에 묶여야 합니다. 경로 없이는 검토를 마쳐도 카드를 만들지 않습니다.

전화는 기본 국내 형식만 검사합니다. 실제 연결/소유자·현재 담당을 검증하지 않습니다. `000-0000-0000`·형식 오류/기관 빈값은 원문을 남기되 전화경로 선택을 제한하고 공식 원문 확인 옵션을 유지합니다. 자동 통화·메시지·예약 요청은 없습니다. 준비 문구는 읽기 전용이고 기본 복사만 제공합니다.

질문/우선순서가 바뀌면 문의경로도 다시 고르고 검토/문구를 무효화합니다. 교체 전5그룹·질문2쌍·우선영향과 기존/새 기관·경로 원문·형식/재선택 이유를 보여줍니다. 취소는 경로/질문/검토/문구를 보존하며 확정은 새 원문으로 다시 준비하게 합니다. 동일 판본의 마지막1회 변경만 되돌리고 새로고침/자료 재수신/새판본에서는 보관하지 않습니다. 검토/선택은 실제 기관 확인/문의 완료 표시가 아닙니다.

지역·요금구분 원문·기재/미제공·검색/초기화·빈 결과·더보기,모바일/키보드·초점 복귀를 제공합니다. 공개표 오류는 재조회하고 독립 공공안내 오류/미연결/부분실패는 질문·경로·준비를 보존합니다. 자유 개인정보/위치·경로·건강·연락처는 입력받지 않으며 검색/선택/준비는 화면 메모리에만 두고 URL/서버/브라우저 저장소·외부 분석으로 보내지 않습니다.

## 기존 API 조합과 비밀값 없는 설정 안내

12,051건 API 목록의 기존3기관 `/api/benefits`를 재사용합니다. 제목/요약/기관명의 자전거/교통 문구를 별도 안내로 찾으며 선택 대여소의 제휴·대여료 지원/개인 자격과 연결하지 않습니다. 각 첫최대100건·성공 캐시 최대30분·화면 첫100건 범위입니다. 빈 결과는 전체 제도 부재가 아닙니다. 기관 수신시각과 수정일/미제공을 구분해 표시합니다.

이번 공식 상세 문서4개는 모두200으로 제목을 확인했습니다. 최신 전체명세·개인 활용승인 상태는 미검증이며 정부 혜택의 기존v3 경로 전체 대조도 완료하지 않았습니다. [광양시 자전거대여소15077184](https://www.data.go.kr/data/15077184/openapi.do)의 공식 서비스 URL `https://apis.data.go.kr/4840000/bcycllend1`와`getbcycllendList1` 오퍼레이션은 확인했지만 **미연결**입니다. 공통키 호환·개인 활용승인·실제 응답은 검증하지 않았습니다. 새 연결이 필요하면 공식 HTTPS 명세/활용신청·승인과 어댑터 구현이 선행돼야 하며 이번에 연결/등록하지 않습니다. 별도 서울 키도 다른 자전거 서비스에 재사용하지 않았습니다.
