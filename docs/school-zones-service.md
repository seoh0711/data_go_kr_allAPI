# 보호구역 확인노트

운영 경로 `/services/school-zones/`. 성인 주민이 공개 시설의 보호구역 표기를 비교하고 **선택근거와 원문별 미확인 질문2개를 붙인 문의 준비서**를 만듭니다. 실제 문의·신고·통학 경로·안전 등급·법적 지정 효력 판단은 하지 않습니다. 개인/아동 정보나 사용자 실제 학교를 받지 않습니다.

## 자료와 해석 범위

[전국어린이보호구역표준데이터15012891](https://www.data.go.kr/data/15012891/standard.do)를2026-10-31 08:33 UTC에 HTTP200으로 직접 확인했습니다. 공개표499행→499기록,6개 지역의 일부이며 기준일2026-07-31~2026-10-14입니다. 전국 전체나 현재 지정/안전/CCTV 작동 현황이 아닙니다. 지역/주소의 원문 표기도 그대로 보존합니다.

보존 필드는 시설명/종류·주소·관리기관·관할 경찰서·CCTV설치여부/대수·지정여부/수정일·도로폭·기준일입니다. 좌표·아동/보호자 정보·경로·자유 제보·사진은 수집하지 않습니다. 추출기는 공식 스키마/행수/필수값이 다르면 중단하며 기존 자료를 덮어쓰지 않습니다. 원문 해시와 수집시점은 `public/school-zones.json`에 있습니다.

Y/N은 기준일 표기입니다. 빈 대수·빈 수정일을0/N/변경 없음으로 만들지 않습니다. CCTV 설치 표기를 현재 작동/사각지대/안전도로 판단으로 바꾸지 않고,지정 표기로 현재 속도제한/법적 적용 범위를 확정하지 않습니다.

## 비교→근거→미확인 질문→다음 행동

2후보×5그룹을 같은 화면에서 비교합니다. 먼저 문의할 시설과 공개 주소·관리기관·관할 중 원문 선택근거를 고릅니다. CCTV 표기/대수,지정/수정일,관리/관할 중 아직 물어볼 질문2개를 고릅니다. 각 질문은 기록ID·기준일·원문값과 연결되며 ‘기관 확인 완료’가 아닙니다. 세 검토 표시도 실제 이해/연락/기관 답변을 증명하지 않습니다.

교체 전5그룹·선택근거·질문별 전후 원문과 초기화 영향을 보여줍니다. 취소는 기존 준비 전체를 보존합니다. 교체 확정은 질문/검토/문구를 초기화하며 문의 후보를 바꾸면 선택근거도 해제합니다. 새로운 근거·질문2개·검토3개가 있어야 다시 준비합니다. 같은 자료 판본에서 마지막1회 변경만 되돌릴 수 있으며 새로고침/재수신/새판본에서는 보관하지 않습니다.

검색/지역/표기 필터·빈 결과·초기화·더보기와 키보드 라디오/체크박스,교체/취소 초점 복귀를 제공합니다. 공개표 오류는 재조회하고 독립 공공안내 실패는 선택·질문·준비를 보존합니다. 검색어/선택/준비는 화면 메모리에서만 처리하며 URL/서버/브라우저 저장소·분석 도구로 보내지 않습니다. 읽기 전용 준비 문구만 기본 복사할 수 있습니다.

## API 조합과 설정 안내

12,051건 카탈로그에서 확인한 기존3기관을 `/api/benefits`로 재사용합니다. 교통/안전 문구의 독립 안내이며 선택 시설·학교·아동 자격과 연결하지 않습니다. 각 첫최대100건·성공 캐시 최대30분·화면 첫100건 범위입니다. 빈 결과는 전체 제도 부재가 아닙니다.

|서비스/공식 문서|기존 HTTPS 경로|
|---|---|
|[행정안전부 대한민국 공공서비스(혜택)15113968](https://www.data.go.kr/data/15113968/openapi.do)|`https://api.odcloud.kr/api/gov24/v3/serviceList`|
|[중앙부처복지서비스15090532](https://www.data.go.kr/data/15090532/openapi.do)|`https://apis.data.go.kr/B554287/NationalWelfareInformationsV001/NationalWelfarelistV001`|
|[지자체복지서비스15108347](https://www.data.go.kr/data/15108347/openapi.do)|`https://apis.data.go.kr/B554287/LocalGovernmentWelfareInformations/LcgvWelfarelist`|

공통 `DATA_GO_KR_SERVICE_KEY` fallback과 기존 기관별 `BENEFITS_GOV24_KEY`/`BENEFITS_CENTRAL_KEY`/`BENEFITS_LOCAL_KEY` override를 보존합니다. 공통 키 사용 가능성과 개별 서비스 활용승인은 별개입니다. 이번에는 새 키·Secrets 등록/복사·권한·지속 접근·서버 어댑터를 변경하지 않았습니다. 필요 시 해당 공식 서비스의 기존 활용승인과 운영 설정을 확인하되 키를 채팅/URL/공개파일/클라이언트에 넣지 마세요.

이번 공식 상세 페이지4개는 모두200으로 서비스 제목을 확인했습니다. 중앙/지자체의 기존 경로·목록오퍼레이션은 문서에서도 확인했습니다. 정부 혜택 페이지는 기존 v3 경로를 포함하지 않아 최신 전체 명세 대조는 미완료이며 실제 운영 응답 검증과 구분합니다. 개인별 활용승인 조건/상태는 미검증입니다.

[대전광역시 어린이보호구역조회서비스15110683](https://www.data.go.kr/data/15110683/openapi.do)의 공식 `https://apis.data.go.kr/6300000/GetSchoListService/getSchoList` 경로도 확인했으나 **미연결**입니다. 공통 키 호환·활용승인·실제 응답을 이번에 검증하지 않았으며 새로운 인증 호출/등록은 하지 않습니다. 연결이 필요하면 공식 활용신청/HTTPS 명세·승인 상태를 먼저 확인해야 합니다. 이 경로의 가상 시설값을 표시하지 않습니다. 서울/계룡/분리배출 보류API는 재호출하지 않습니다.
