## 수정한 실행 결함

1. Cloudflare Workers의 기본 fetch에 `redirect: error`를 넘기면 요청 전 TypeError가 발생했습니다. native 호출은 `manual`로 하고 3xx를 직접 거부하여 키가 다른 목적지로 따라가지 않는 정책을 유지했습니다.
2. native fetch에는 URL 문자열을 전달하고 기본 글로벌 receiver를 유지합니다. 정해진 제공기관 주소 이외의 목적지를 추가하지 않았습니다.
3. 타임아웃은 요청별 native AbortController로 처리하고 finally에서 타이머를 해제합니다.
4. JSON/XML 응답을 제한된 크기로 읽고, 인증·활용승인·IP 제한·할당량·빈 결과·HTTP·형식 오류를 구분합니다. 공개 오류는 고정 분류와 허용된 코드만 포함하며 오류 메시지·스택·원문·인증 URL을 출력하지 않습니다. 화면에도 안전한 한국어 오류 분류를 표시합니다.
5. 지자체 복지의 실제 XML 루트는 명세의 response 외 wantedList도 사용했습니다. 둘 다 정상 코드·건수·필수 서비스 필드를 검증한 후 처리합니다. 중앙부처의 등록일/수정일을 분리하고 변경된 정규화 결과에 맞춰 캐시 버전을 올렸습니다.
