# 분리배출 길잡이

기존 공개 데이터 아틀라스의 여섯 번째 생활 서비스. 경로 `/services/recycling/`, 서버 경로 `/api/recycling`.

## 목적과 자료 범위

지역별 종량제봉투 가격을 공개표에서 찾고, 품목별 대표 배출방법과 제주시 재활용도움센터 안내를 별도 기관 조회로 확인합니다. 배출요일·시간·규정·수거 가능 여부·현재 가격을 추정하지 않습니다.

### 키 없이 사용할 수 있는 실제 공개표

- 공식 원문: [전국종량제봉투가격표준데이터](https://www.data.go.kr/data/15025538/standard.do)
- 공개 HTML 표 첫 일부 499행을 2026-10-27 UTC에 인증 없이 수집했습니다. 전국 전체 목록이 아닙니다. 16개 표기 시도의 일부 기록이며 중복 ID는 없습니다. 개별 자료 기준일은 **2020-07-07~2026-09-26**입니다. 오래된 기록이 포함되어 현재 구매 가격을 보장하지 않는다는 안내를 상단과 상세에 표시합니다.
- 용도·처리방식·사용대상·시군구를 별도 보존합니다. 같은 지역 기록을 합치거나 가장 싼 가격으로 추천하지 않습니다. 15개 용량을 제공하며 원문 0/누락/유효하지 않은 가격은 무료로 해석하지 않습니다. 가격 확인 필요로 표시하고 상세에 원문을 함께 보여줍니다.
- 수집 스크립트 `scripts/snapshot_recycling.py`, 자료 `public/recycling-bags.json`. `collectedAt`, `htmlSha256`, `parsedRows`, `coverage`와 개별 기준일을 기록합니다.
- [전국생활쓰레기배출정보표준데이터](https://www.data.go.kr/data/15025450/standard.do)는 현재 공식 페이지가 파일데이터 15075534로 안내되고 공개 표의 행 자료를 확인하지 못했습니다. 따라서 해당 지역별 배출 규칙을 복제하거나 추정하지 않고 공식 안내 링크만 제공합니다. 표의 부재를 빈 규정이나 전국 적용 규칙으로 해석하지 않습니다.

### 카탈로그 및 공식 Swagger를 대조한 API 2개

1. [기후에너지환경부_분리배출 정보조회 서비스 (15156866)](https://www.data.go.kr/data/15156866/openapi.do)
   - HTTPS `https://apis.data.go.kr/1482000/WasteRecyclingService/getItem`
   - 필수 `serviceKey`, `pageNo`, `numOfRows`, `itemNm`. `itemNm`, `dschgMthd`를 표시합니다.
   - 생수병·우유팩·캔·종이상자·스티로폼·비닐의 준비된 6개 품목만 조회하며 자유 입력·개인 주소는 전송하지 않습니다. 같은 서비스의 getSpot은 주소/좌표를 요구하므로 사용하지 않습니다.
   - 대표 배출방법으로 표시하며 지역별 규칙을 대신하지 않습니다. 기관 자료 기준일이 응답에 없으므로 미제공으로 표시합니다.
2. [제주특별자치도 제주시_재활용도움센터 조회 서비스 (15109194)](https://www.data.go.kr/data/15109194/openapi.do)
   - HTTPS `https://apis.data.go.kr/6510000/recycleCenterService/getRecycleCenterList`
   - 필수 `serviceKey`, 선택 `pageNo`, `numOfRows`, `emdNm`. 앱은 첫 20행만 요청하고 개인 위치/주소와 읍면동 조건을 전송하지 않습니다.
   - `emdNm`, `rnAdres`, `operTimeInfo`, `etcCn`, `regDt`만 표시합니다. 등록시각과 서버 수신시각을 구분하고 현재 운영 상태로 해석하지 않습니다.

## 인증·보안·개인정보

기존 `DATA_GO_KR_SERVICE_KEY` fallback을 사용하며 호환용 override는 각각 `RECYCLING_ITEMS_KEY`, `RECYCLING_CENTERS_KEY`입니다. 신규 키 생성·등록·복사·Secrets 변경·새 권한·새 지속접근은 하지 않습니다. 공통키 사용과 개별 API 활용승인은 별개입니다. 인증/승인 오류가 발생하면 사용자가 위 정확한 서비스의 활용신청·승인 및 기존 키 적용 상태를 포털에서 확인하도록 안내합니다. 키 값은 채팅에 보내지 않아도 됩니다.

서버는 source/item 쿼리를 allowlist로 검증하고 중복·임의 주소·좌표·자유 입력은 upstream 호출 전 400으로 거절합니다. 서버의 API 목적지는 위 고정 HTTPS 주소뿐입니다. 서울 키는 사용하지 않습니다. 10초 요청 제한, 12초 브라우저 제한, 성공 결과 최대 15분 캐시, 최대 20행, 2MiB 응답 제한, XML 외부 엔티티 거절, redirect 차단과 비밀값 반사 방어를 적용합니다. 원문 에러·인증 URL·키를 브라우저로 전달하지 않습니다. 공통 오류 분류에 공식 명세의 무자료 코드 `3`을 `03`과 동일하게 추가했고, 제주시 공식 명세의 잘못된 인증키 코드33은 이 서비스에서 인증 오류로 분류합니다.

사용자 검색·시도·시군구·용도·용량 선택은 브라우저 메모리에서 처리합니다. localStorage·쿠키·DB에 저장하지 않습니다. 위치 권한·가입·예약·연락처 입력 없음. 공개 기관 전화번호만 안전한 tel 링크로 제공합니다. 기관 텍스트는 React 기본 이스케이프로 렌더링합니다. 기관 조회는 사용자가 버튼을 누를 때만 실행합니다. 스냅샷·기관 조회를 분리하며 가상 예시가 없습니다.
