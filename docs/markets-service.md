# 장보기수첩

기존 공개 데이터 아틀라스의 여덟 번째 생활 서비스. 경로 `/services/markets/`.

## 사용자 문제와 기능

전통시장 방문 후보를 시장 유형·취급품목·개설주기·편의시설 원문으로 고르고, 부산 시장은 주소에 명시된 같은 구·군의 주차 참고자료를 별도로 확인합니다. 상품 가격·다음 장날·현재 영업·상품권 혜택·시장 전용 주차장·주차 할인·거리·가까운 순서를 추정하지 않습니다.

시장 공개표는 기존 어느 서비스에도 없던 새 자료입니다. 시장 상세에서 부산 주차 참고 화면으로 이동하는 흐름을 추가했으며, 두 기존 주차 API는 이미 승인된 연결 그대로 재사용합니다. 새 API 어댑터·키·지속 접근을 만들지 않았습니다.

## 공식 데이터와 시점

### 시장 공개표

- [전국전통시장표준데이터](https://www.data.go.kr/data/15012894/standard.do)
- 2026-10-27 UTC에 공개 HTML 표 일부499행을 키 없이 수집했습니다. **원자료는 모두2025-11-10 기준의 과거 정보**입니다. 현재 영업·상품권 사용·편의시설 이용 가능 여부와 혼동하지 않도록 헤더·상단·상세에 표시합니다.
- 16개 원문 표기 시도 일부이며 부산 시장6개 포함. 전국 전체 목록이 아닙니다. 원문의 행정구역 표기와 오탈자도 현재 명칭으로 추정해 고치지 않았습니다.
- 시장명/주소로 만든499개 고유 ID입니다. 유형·개설주기·점포수·취급품목·상품권·홈페이지·화장실/주차장 보유 여부·개설연도·공개 문의전화·기준일 원문만 보존합니다. 위경도·상인 이름·이용자 위치/구매정보는 수집하지 않습니다.
- `scripts/snapshot_markets.py`로 수집을 재현하고 `public/markets-snapshot.json`에 `collectedAt`, `parsedRows`, `htmlSha256`, `coverage`, 기준일·지역 분포를 기록합니다. 가상 예시 없음.
- Y/N 외의 시설 보유 값은 미제공으로 구분합니다. 점포수0을 폐업으로, 빈 상품권 필드를 사용 불가로, 상설장/개설주기를 오늘 영업이나 다음 개설일로 해석하지 않습니다.

### 카탈로그에서 대조한 기존 API 두 개

[부산광역시_공영주차장 정보 조회 (15004683)](https://www.data.go.kr/data/15004683/openapi.do)

- 공식 HTTPS: `https://apis.data.go.kr/6260000/BusanPblcPrkngInfoService/getPblcPrkngInfo`
- 기존 ServiceKey/pageNo/numOfRows/resultType 요청과 정상코드 검증·주소/요금/운영시간 파싱을 재사용합니다. 첫 최대20행이며 전체 목록이 아닙니다.
- **공식 명세의 guNm은 관리기관명이며 구·군이 아닙니다.** 기존 어댑터의 district 필드에 담긴 guNm을 위치로 해석하지 않습니다. 새 서비스는 부산 출처 row.address의 시작 부분에 명시된 구·군 토큰만 비교합니다. 주소에서 구·군 확인 불가 시 미제공으로 취급하며 관리기관명으로 보완하지 않습니다. 같은 행정구역일 뿐 시장 인근/전용/제휴 관계를 뜻하지 않습니다.

[부산시설공단_공영주차장 시설 현황 조회 서비스 (15157490)](https://www.data.go.kr/data/15157490/openapi.do)

- 현재 공식 Swagger에서 HTTPS와 `/getParkingInfoList_v2`를 확인했습니다. 기존 요청 `https://apis.data.go.kr/B552587/ParkingInfoService_v2/getParkingInfoList_v2`를 재사용합니다.
- 기관 제공 가능 대수와 최종 갱신시각 원문을 표시합니다. 이 목록에는 주소·구군이 없으므로 시장 후보나 첫 API 시설과 매칭/합산하지 않습니다. 현재 입차나 빈자리 보장 아님. 유효한0은0대로, 결측/불일치 수량은 미제공으로 표시하는 기존 계약을 유지합니다.

기존 `/api/parking`을 버튼으로만 호출합니다. 부산 안내 최대15분/시설공단 가능 대수 최대1분 캐시와 기존10초 요청 제한,2MiB JSON/XML 방어,DOCTYPE/ENTITY 거절,redirect 차단,비밀 반사/정형 오류 처리를 그대로 사용합니다. 브라우저12초 제한. 기존 서버·파싱·인증·캐시 코드는 수정하지 않았습니다.

## 인증·설정·개인정보

기존 `DATA_GO_KR_SERVICE_KEY` fallback과 `PARKING_BUSAN_KEY`/`PARKING_AVAILABILITY_KEY` override를 재사용합니다. 신규 키·등록·복사·Secrets·권한·계정·비용·지속 접근은 없습니다. 공통키와 서비스별 활용승인은 별개이며 오류가 발생하면 위 정확한 두 서비스의 기존 활용승인/키 적용 상태를 공식 포털에서 확인하면 됩니다. 앱에서 새 신청을 하지 않으며 키 값은 채팅에 보낼 필요가 없습니다.

사용자 시장·주소 검색·지역·취급품목·시설 필터·선택 후보·주차 구군·검색어는 브라우저 메모리에서만 처리합니다. `/api/parking`에는 쿼리를 붙이지 않으며 기관에 시장 선택/위치/이용자 정보를 보내지 않습니다. localStorage/쿠키/DB 저장 없음. 위치 권한·가입·예약·결제·연락처 입력 없음. 외부 홈페이지는 원문이 검증 가능한 HTTPS URL일 때만 링크하고 HTTP를 임의로 HTTPS로 바꾸지 않습니다. 공개 문의전화는 검증된 tel 링크만 제공하며 React 기본 이스케이프를 유지합니다.
