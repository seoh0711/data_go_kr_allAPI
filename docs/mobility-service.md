# 이동충전길

데이터 아틀라스의 열두 번째 생활 서비스. `/services/mobility-power/`.

## 목적과 기능

전동휠체어 충전시설을 지역·시설명·주소·설치 장소 설명으로 찾고, 평일/토요일/공휴일 시간·관리기관·공개 연락처를 확인합니다. 공기 주입과 휴대전화 충전 Y/N 원문 필터, 기준일 최신순, 더 보기, 키보드 상세/ESC/초점 복원, 모바일 화면을 제공합니다. 시설 상세에서 보조기기 공공안내 화면으로 이동할 수 있지만 시설과 제도의 연계·개인 자격으로 매칭하지 않습니다. 기존 서비스에 없는 충전시설 자료와 설치 위치 확인 흐름을 추가했습니다.

## 공식 자료와 API 조합

[전국전동휠체어급속충전기표준데이터](https://www.data.go.kr/data/15034533/standard.do)의 인증 없는 공식 HTML 공개표 499행을 2026-10-28 UTC 수집했습니다. 원자료 기준 **2026-07-31~2026-09-18**, 원문 지역 10개 일부이며 전국 전체가 아닙니다. 지역명은 원문 그대로 보존합니다. 같은 이름·주소의 조합은493개로,조건 등이 다른6개 추가 기록을 합치지 않았습니다. 공식 표준 설명의 갱신주기는 반기이며 실시간 관측이 아닙니다. `public/mobility-power-snapshot.json`에 수집시각·기준일·범위·행 수·지역별 분포·원본 HTML SHA256을 기록했습니다. `scripts/snapshot_mobility.py --html <공식 HTML 경로>`로 재현합니다. 보존 필드 조합으로 ID를 만들고 동일 이름/주소의 조건·기준일 차이는 보존합니다. 위경도·시군구 코드·사용자/기기 식별자는 저장하지 않습니다.

현재 동시사용가능대수는 설치 규모 원문이며 빈 자리 수가 아닙니다. Y/N은 자료 기준일 표기이며 작동 상태가 아닙니다. 동일 시작/종료시간을 휴무나 24시간으로 해석하지 않습니다. 자료명의 ‘급속’은 공식 분류명이며 실제 충전 속도·기기 호환성·이용 대상·요금·접근 가능한 경로·현재 개방을 보장하지 않습니다. 방문 전 관리기관 확인을 안내합니다.

## 연결 설정과 개인정보

기존 공통 `DATA_GO_KR_SERVICE_KEY` fallback과 `BENEFITS_GOV24_KEY`/`BENEFITS_CENTRAL_KEY`/`BENEFITS_LOCAL_KEY` override 호환성을 유지합니다. 현재 공통 키는 운영에 사용자가 직접 등록한 상태이며 이번 작업에서 생성·복사·등록·수정하지 않습니다. 연결 문제가 생기면 위 정확한 서비스의 기존 활용승인과 기존 운영 변수 적용 상태를 확인하면 됩니다. 공통키 사용과 각 서비스 활용승인은 별개이며 채팅에 키를 보낼 필요가 없습니다. 새 API/권한·지속 접근·유료서비스·공개범위·미리보기 설정 변경 없음.

위치 권한·건강/장애·소득·가족·기기 식별정보를 받지 않습니다. 지역/검색/선택/기관 필터는 메모리에만 있고 `/api/benefits`에는 쿼리를 보내지 않습니다. localStorage·쿠키·DB 저장·자동 개인화 없음. 공개시설 연락처는 검증한 tel 링크이며 자동 발신하지 않습니다. 공식 링크 검증·React 이스케이프를 재사용합니다. 원문 오류·인증URL·비밀값을 브라우저에 출력하지 않습니다. 기존 요청제한·응답크기 제한·XXE/redirect 차단·정형 오류·부분 장애 처리를 유지합니다.
