# API 조합노트

[운영 경로](https://data-go-kr-api-atlas.pages.dev/services/api-planner/)는 공공서비스 제작자가 기존 연결의 조건을 비교하고 비밀값 없는 조합 준비서를 작성하는 도구입니다. 시민 시설 탐색17개와 달리 API 계약·인증·호출 범위·한계를 검토하는 과업입니다. 원격 키 설정·활용신청·새 서버 등록·사용자 코드 실행·API 자동 조합 배포는 하지 않습니다.

## 확보한 자료만 사용

기존 `public/catalog.json`의12,051건에서 아래7개 목록 레코드를 그대로 추출한 `public/api-planner.json`과 현재 저장소 어댑터 설정/구현을 조합합니다. `scripts/snapshot_api_planner.py`가 출처 카탈로그 해시·목록 수집시각·추출 범위를 기록합니다. 이름·기관·형식·수정일은 목록 스냅샷이고,경로·호출상한·성공 캐시는 현재 앱 구현 범위입니다. 기관 전체 API의 한도나 최신 명세라고 단정하지 않습니다.

공식 문서는 기존 서비스에서 확인한 기록과 연결 목록을 근거로 링크합니다. 이번 공식 자료 조회503/문서 도구 형식 오류로 **최신 명세 재검증은 미완료**입니다. 링크의 현재 가용성을 보장하지 않습니다. 기존 코드의 JSON/XML 정상코드·형식 검증은 유지하며 브라우저에는 정규화 JSON만 전달됩니다. 목록에 JSON이라 적힌 항목과 기관이 제공하는 다른 포맷을 임의 동일시하지 않습니다.

인증은 기존 `DATA_GO_KR_SERVICE_KEY` fallback과 각 기존 기관별 override 변수입니다. 변수명만 표시하며 키 값 입력·출력·복사/등록은 하지 않습니다. 공통 키로 각 서비스의 활용승인이 자동 확보되는 것은 아닙니다. 필요한 조치는 각 공식 서비스의 기존 활용승인/운영 적용 확인이며 이번에 승인·권한·Secrets를 변경하지 않습니다. 서울/계룡/분리배출 보류 API는 선택/호출하지 않습니다.

## 비교·검토·준비 흐름

명칭/기관,목록 시점/공식 근거,기관 경로/형식,앱 호출 범위/캐시,인증/확인할 한계의5그룹을 두 후보에서 비교합니다. 조합 선택만으로 기능상 호환·지역/레코드 매칭·개인 적합성·새 서비스 구현 가능을 보장하지 않습니다. 비교하는 API가 같은 분야일 필요는 없으며 조합 준비 정보만 제공합니다.

검토3항목은 공통키/활용승인 차이,첫 페이지/캐시 한계,공식 명세/현재 응답 재확인입니다. 체크는 문구를 읽었다는 표시이며 실제 기관 확인이나 이해도를 증명하지 않습니다. 모두 표시해야 준비서가 생성됩니다. 후보가 바뀌면 검토/준비서를 초기화하고,검토가 바뀌거나 응답을 다시 조회하면 낡은 준비서를 제거합니다. 검색 초기화·기관 실패 시 후보/검토는 유지합니다.

현재 상태는 확인 버튼 전 ‘아직 확인 전’입니다. 버튼은 선택 후보의 **기존 분야 경로**를 호출하므로 같은 분야의 기관들이 함께 조회됩니다. 실제 행 내용 대신 기관 정상/빈/키 없음/실패 상태·수신시각·행 수만 표시합니다. 오류 시 과거 성공으로 채우지 않습니다. 캐시 자료도 수신시각과 함께 보여 현재 이용·승인 보장으로 확대하지 않습니다. 첫 수신 범위가 전체 데이터 규모는 아닙니다.

개인 위치·건강·서비스 목적·키·사용자 코드·자유 메모 입력은 없습니다. 검색/선택/검토/준비 문구는 화면 메모리에만 존재하고 브라우저 저장소·URL·서버로 보내지 않습니다. 외부 분석·권한·비용을 추가하지 않습니다.

## 목표와 검증 기록

동일 회차의 화장실 자료503 차단은 숨기지 않고 [회차002 복구 기록](improvements/002-toilets.md)에 보존합니다. 복구 전에 실제 운영 아틀라스의 API 검색/상세3조건과 직전 다시쓰는센터3조건을 측정하고 별도 세 축 목표를 고정했습니다. 기술 검사·대리 과업·실사용자 성과를 구분합니다. 실사용자 제작 성공·시간절감·만족도는 미측정입니다. 최종 테스트·게시·원격 SHA는 회차 기록과 종료 보고를 확인하세요.
