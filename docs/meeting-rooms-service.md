# 모임자리 준비

[운영 경로](https://data-go-kr-api-atlas.pages.dev/services/meeting-rooms/)는 모임 공간을 알아보는 사람이 공개 회의실/강의실 두 후보를 비교하고,원문의 확인 필요사항을 검토해 문의 준비서를 만드는 서비스입니다. 기존 운동한칸의 종목별 체육시설 탐색과 달리 대관 문의의 요금 기준·수용인원·설비·신청방법을 다룹니다. 예약·신청·기관 연락·견적 확정·현재 빈자리/사용 적합성 판정은 하지 않습니다.

## 실제 공개 자료

[전국공공시설개방정보표준데이터15013117](https://www.data.go.kr/data/15013117/standard.do)를2026-10-30 14:31 UTC에 HTTP200으로 직접 수집했습니다. 원문499행에서 시설 유형이 정확히 ‘회의실’ 또는 ‘강의실’인 **69기록**을 추출했습니다. 기준일 **2026-08-31~2026-10-14**,주소 원문 앞 토큰 기준5개 지역의 일부입니다. 전국 전체/현재 운영 정보/고유 시설69곳이라고 단정하지 않습니다. 이전 회차의503 이력은 보존하며 이번 한 페이지 성공을 모든 기관 복구로 확대하지 않습니다.

`scripts/snapshot_meeting_rooms.py --html <직접 확보한 공식 HTML 경로>`로 재현합니다. 수집시각·499/69행·범위·원문 SHA256은 `public/meeting-rooms.json`에 있습니다. 명칭/장소명/유형·주소·전화·관리기관/부서·시간/휴무·유료표기/기준시간/사용료/초과조건·수용인원·설비·신청방법·기준일만 보존하고 위경도·사진·개인정보는 제외합니다. 같은 보존 필드의 완전 중복만 합치며 이번69행은 그대로69기록입니다.

검색·지역/유형/유료 원문/양수 정수 수용인원 기재 필터를 제공합니다. ‘50명’ 등 혼합 표기는 원문으로 보존하고 숫자 필터에서 추정하지 않습니다. 수용인원 표기가 있어도 모임 규모 적합성이나 현재 사용 가능을 판단하지 않습니다. ‘0’·빈 칸·시작/종료 동일 시간을 무료·24시간·현재 예약 가능으로 해석하지 않습니다. 원자료에 적힌 금액/기준시간/초과조건만 보여 주며 곱셈·합산·단위 변환·세금/부대비용 추정·최종 요금 계산을 하지 않습니다.

첫 두 공개 기록에는 ‘부대시설 미제공’·‘사용 기준시간 원문 확인’·‘초과 시간/요금 조건 미제공’의 확인 신호가 있습니다. 결측/양수 기준 여부에 따라 질문을 만들고 문의 준비서에도 포함합니다. 0을 결측으로 바꾸지 않고 원문0을 유지한 채 현재 조건을 확인하도록 합니다.

## 검토·문의 준비와 실수 복구

두 후보의 명칭/주소/공개 연락처,기준일/공식 근거,시간/휴무,사용료/기준·초과,수용인원/설비/신청 원문5그룹을 비교합니다. 먼저 문의할 후보를 직접 선택하고 검토3항목을 표시해야 준비서를 만들 수 있습니다. 검토는 문구를 읽었다는 표시이며 기관 확인/이해도/예약 완료가 아닙니다. 후보/문의 후보가 바뀌면 과거 검토·문구를 무효화하고,검토를 바꾸면 문구를 제거합니다. 검색 초기화·API 실패는 준비 상태를 유지합니다.

되돌리기는 메모리에서 **같은 공개자료 판본의 마지막 변경1회**만 복구합니다. 선택 비우기 실수 뒤에는 원래 후보·문의 후보·검토·준비 문구를 복원하고 비교 제목으로 초점을 옮깁니다. 두 번째 되돌리기는 제공하지 않습니다. 새로고침·자료 재수신·판본 불일치 때 이전 상태를 복구하지 않습니다. 오래된 검토를 최신 기관 확인으로 취급하지 않으며 복구 안내에도 그 경계를 표시합니다. API 안내는 준비 문구에 결합하지 않는 독립 자료여서 안내 실패가 원문 기반 계획을 덮어쓰지 않습니다.

## 기존 API 조합과 설정

실제12,051건 목록의 기존 세 연결을 `/api/benefits`에서 재사용합니다. 각각의 공식 링크와 기존 서버 경로는 아래와 같습니다. 신규 인증 목적지/키/권한/지속 접근은 만들지 않습니다.

|기존 제공기관 서비스|기관 HTTPS 경로|앱 수신 범위|
|---|---|---|
|[행정안전부_대한민국 공공서비스(혜택) 정보15113968](https://www.data.go.kr/data/15113968/openapi.do)|`https://api.odcloud.kr/api/gov24/v3/serviceList`|JSON 첫최대100건|
|[한국사회보장정보원_중앙부처복지서비스15090532](https://www.data.go.kr/data/15090532/openapi.do)|`https://apis.data.go.kr/B554287/NationalWelfareInformationsV001/NationalWelfarelistV001`|XML 첫최대100건|
|[한국사회보장정보원_지자체복지서비스15108347](https://www.data.go.kr/data/15108347/openapi.do)|`https://apis.data.go.kr/B554287/LocalGovernmentWelfareInformations/LcgvWelfarelist`|XML 첫최대100건|

제목·요약·기관명에서 공간/대관/회의/평생학습/주민 문구만 단순 검색합니다. 특정 장소의 대관 지원·제휴·신청 자격으로 매칭하지 않습니다. 각 첫100건과 최대30분 성공 캐시 범위이며 전체 제도 부재/전국 시설 목록으로 확대하지 않습니다. 기관 수정일 원문과 KST 수신시각·미연결/빈/부분 실패를 구분합니다.

기존 `DATA_GO_KR_SERVICE_KEY` fallback과 `BENEFITS_GOV24_KEY`/`BENEFITS_CENTRAL_KEY`/`BENEFITS_LOCAL_KEY` override를 유지합니다. 공통 키와 각 서비스 활용승인은 별개입니다. 오류 시 위 정확한 서비스의 기존 활용승인과 운영 변수 적용을 확인해야 하며 이번 회차에 설정 변경/키 복사/등록을 하지 않습니다. 새 목록 API15077519 등의 존재는 카탈로그에서 확인했으나 새 연결/활용승인/현재 명세 호환성을 검증하거나 추가 호출하지 않았습니다. 서울/계룡/분리배출 보류 API도 실제 재호출하지 않습니다.

## 개인정보와 검증 범위

모임 내용·단체/참석자·날짜/시간·개인 연락처·개인 위치를 입력받지 않습니다. 공개정보 검색/시설 조건 필터·선택/검토·복구/준비 문구는 화면 메모리에만 두고 URL/서버/브라우저 저장소·외부 분석으로 전송하지 않습니다. 키 값이나 자유 메모 칸이 없고 복사도 사용자의 기본 브라우저 기능만 제공합니다.

직전 API 조합노트와 관련 운동한칸의 실제 기준선을 측정하고 목표를 구현 전에 고정했습니다. [회차003 계획·관측·실패/재검증·배포 기록](improvements/003-meeting-rooms.md)을 확인하세요. 자동화 대리 과업·기술 검사와 실제 문의/대관·만족/시간 절감은 구분하며 실사용자 outcome은 미측정입니다.

이번 공식 문서 재확인 결과: 위 세 공공안내 서비스의 공식 상세 페이지는 모두HTTP503이어서 최신 명세/활용신청 조건은 재검증하지 못했습니다. 기존에 확인한 문서 기록·현재 설정/파서를 근거로 사용하고 운영 실제 응답 검증과 문서 가용성을 분리합니다. 회의실/강의실의 원문 표/스키마는 이번HTTP200으로 직접 검증했습니다.
