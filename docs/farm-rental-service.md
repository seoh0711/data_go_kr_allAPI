## 사용자 문제와 구현

농작업 준비 시 농기계 임대사업소의 위치·연락처·장비 분류별 보유 원문을 찾고 농업 관련 공공안내를 별도로 확인합니다. 사업소/주소/기타 보유정보 검색,시도·주소의 세부지역·양수 보유대수 기재 장비 필터,초기화/빈 결과/더 보기,키보드 상세/ESC/초점복원,사업소→독립 공공안내 탭과 초점 이동,모바일 화면을 제공합니다. 기존 시설 서비스의 이름 변경이 아니라 새 임대사업소/장비 자료와 장비 보유 원문 확인 흐름을 추가했습니다.

농지 주소·농업인 등록·소득·개인 연락처를 입력받지 않습니다. 현재 대여 가능 수량·예약·임대 대상·요금·교육 자격·기계 적합성·작업/운전 방법을 판단하거나 신청/예약하지 않습니다. 해당 조건과 현재 장비 상태는 사업소에 문의합니다.
