# 두곳방문 노트

[운영 경로](https://data-go-kr-api-atlas.pages.dev/services/two-visits/)는 도서관 방문과 공원 산책을 함께 알아보는 사람이 유형별 한 곳의 공식 근거를 묶고,교체 전후 조건과 초기화 영향을 검토해 방문 노트를 만드는 서비스입니다. 문화쉼표·공원한바퀴의 개별 시설 탐색과 달리 **서로 다른 두 유형의 준비와 교체 결정**이 목적입니다. 실제 방문·기관 연락·예약·최적 경로·이동시간/거리·같은날 방문 가능을 제공하지 않습니다.

## 이미 확보한 두 공개표

신규 시설 수집을 주장하지 않고 기존 원문/범위를 유지합니다. 원본JSON을 수정·복제하지 않고 같은 공개 경로에서 읽습니다.

|공식 출처/공개 파일|수집일|기준일/범위|
|---|---|---|
|[전국도서관표준데이터15013109](https://www.data.go.kr/data/15013109/standard.do),`culture-libraries.json`|2026-10-26|2026-01-13~2026-09-28,공식 페이지 일부499기록|
|[전국도시공원정보표준데이터15012890](https://www.data.go.kr/data/15012890/standard.do),`parks-snapshot.json`|2026-10-27|2026-07-31~2026-09-16,공식 페이지 일부499기록|

두 표의 수집일/기준일/원문 해시/범위를 구분해 표시합니다. 전체 전국 목록·고유 시설998곳·현재 개방을 뜻하지 않습니다. 주소의 지역명은 원문 문자열로만 필터하고 행정구역/현재 관할을 정규화하지 않습니다. 같은 지역명이라도 인접하거나 한 동선으로 방문할 수 있음을 뜻하지 않습니다.

공원 운영시간/휴무·요금과 도서관 시설 세부정보/이용요금은 원자료 미제공으로 표시하며 추정하지 않습니다. 도서관의 평일/토요일/공휴일 시각·휴관일,공원의 운동/유희/편익/교양/기타 시설 표기는 원문 그대로 보존합니다. 같은 시작·종료시각을24시간/휴무로 해석하거나 보유 시설을 현재 작동/사용 적합성으로 판단하지 않습니다.

이번 공식 자료 접근 확인에서 캠핑 표준15021139는HTTP200의 제목/설명을 받았지만 실제 시설 행이 없었고,자동차검사소15021107·자전거대여소15017326은 각HTTP503이었습니다. 이를 우회하거나 반복하지 않고 이미 적법하게 확보한 두 자료로 범위를 정했습니다. 공식 자료/새 API의 현재 가용성이나 활용승인을 추정하지 않습니다.

## 두 출처의 준비와 교체 검토

도서관1곳과 공원1곳만 선택하며 사용자가 정한 참고 순서는 이동 추천이 아닙니다. 명칭/주소·공개전화·날짜/공식 근거·시간 원문·시설/현재 확인할 한계5그룹을 각 장소에서 확인하고,검토3항목을 표시해야 노트를 만듭니다. 검토는 문구를 읽었다는 표시이며 실제 기관 확인·이해도·방문 성공을 증명하지 않습니다.

같은 유형의 다른 기록을 고르면 즉시 덮어쓰지 않고 전/후5그룹을 보여 줍니다. 실제 문자열이 다를 때만 ‘변경’,같으면 ‘동일’입니다. 미제공/동일 값을 변화로 부풀리지 않습니다. 확정하면 검토3개와 과거 준비 문구가 초기화됨을 미리 알립니다. 검토 중에는 원래 선택·검토·문구를 유지하고,취소하면 그대로 돌아갑니다. 확정 후에는 해당 유형만 바꾸고 다른 유형/참고 순서를 유지하되 재검토해야 새 노트를 만듭니다.

같은 두 공개표 판본에서 마지막1회 선택/검토 변경을 되돌릴 수 있습니다. 교체 확정 전 상태와 문구를 정확히 복구하며 새 자료 판본·새로고침·재수신에서는 과거 계획을 보관하지 않습니다. 미리보기 중 충돌하는 선택/검토·되돌리기를 막고,취소는 원래 선택 버튼으로,확정/복구는 비교 제목으로 초점을 돌립니다.

두 자료 중 하나가 실패하면 정상 목록은 열람할 수 있지만 유형별 완성 근거가 부족하므로 선택/준비를 제한합니다. 오류를 예시 기록으로 채우지 않습니다. 재시도는 두 표를 다시 확인하며 선택/검토·복구를 초기화한다고 안내합니다.

## 기존 기상·대기 API 조합

실제12,051건 카탈로그의 기상청15084084/에어코리아15073861과 기존 설정·파서를 재사용합니다. 새 인증 목적지/키·서버 어댑터/권한은 추가하지 않습니다.

|공식 문서|기존 기관 HTTPS 경로|기존 설정|
|---|---|---|
|[기상청_단기예보 조회서비스15084084](https://www.data.go.kr/data/15084084/openapi.do)|`https://apis.data.go.kr/1360000/VilageFcstInfoService_2.0/getUltraSrtNcst`|공통 `DATA_GO_KR_SERVICE_KEY` fallback,기존 `KMA_SERVICE_KEY` override|
|[한국환경공단_에어코리아_대기오염정보15073861](https://www.data.go.kr/data/15073861/openapi.do)|`https://apis.data.go.kr/B552584/ArpltnInforInqireSvc/getMsrstnAcctoRltmMesureDnsty`|공통 fallback,기존 `AIRKOREA_SERVICE_KEY` override|

기존 `/api/parks?city=` 경로는 수원·성남·고양·용인4개 수동 선택 참고 지역만 받습니다. 선택 시설/검색어·실제 위치·개인정보를 보내거나 시설과 매칭하지 않습니다. 관측은 측정소/격자 참고이며 현장·이동 경로·방문 예정시각의 예측이 아닙니다. 기관 관측시각(KST)과 서버 응답 확인시각을 구분하며,제공되지 않는 기관별 수신시각을 만들지 않습니다. 미연결/빈/부분 실패·결측과 숫자0을 구분합니다. 평가 등급/건강 판단·행동 권고를 생성하지 않고 준비 문구에 현장 상태로 포함하지 않습니다. 현재 선택 지역의 응답만 표시해 다른 지역 관측이 혼합되지 않게 합니다. 서버 응답 캐시는 기존 최대120초입니다.

두 API의 공식 상세 페이지는2026-10-30 이번 조회에서각HTTP503이어서 최신 명세/활용신청 조건을 재확인하지 못했습니다. 기존 검증 기록·현재 구현·운영 실제 응답 검증을 구분하고 제품에 명시합니다. 공통 키와 각 서비스 활용승인은 별개입니다. 오류 시 정확한 위 서비스의 기존 승인/운영 적용을 확인해야 하며 새 키/권한/설정을 이 회차에서 만들지 않습니다. 서울/버스 키는 이 경로로 전달하지 않으며 계룡/분리배출 등 보류API를 실제 재호출하지 않습니다.

## 개인정보·성과 한계

동행인/가족·아동 정보·일정/날짜·건강·개인 연락처·위치 권한/외부 분석을 추가하지 않습니다. 검색/지역 필터·선택/순서·검토·교체/복구·노트는 화면 메모리에만 두고 URL/서버/브라우저 저장소로 보내지 않습니다. API에는 미리 정한4개 참고 지역 코드만 전달합니다. 노트는 읽기 전용으로 기본 복사 기능만 사용합니다.

구현 전 직전 모임자리 준비와 관련 공원한바퀴를 실제 측정하고 목표를 고정했습니다. [회차004의 기준선·목표·관측·검증/배포 기록](improvements/004-two-visits.md)을 확인하세요. 자동화 대리 과업·기술 통과와 실제 방문·이해·만족/절감시간은 구분하며 실사용자 outcome은 미측정입니다.
