# 불빛연락망

기존 데이터 아틀라스의 열세 번째 생활 서비스. 경로 `/services/lighting/`.

## 사용자 문제와 구현 범위

보안등에 관해 문의할 때 시설 위치명·주소·관리기관·공개 연락처를 찾기 어렵다는 문제를 해결합니다. 검색과 주소의 읍/면/동·설치형태·설치연도 원문 필터,더 보기,상세/ESC/초점 복원,읽기 전용 문의 참고정보 선택,모바일 화면을 제공합니다. 정보 선택은 브라우저 텍스트 선택이며 클립보드·위치·개인정보 권한을 요청하지 않습니다. 신고 접수/전송·수리 결과·현재 점등/고장·경로 밝기/안전 등급을 계산하거나 표시하지 않습니다. 기존 시설 탐색의 이름 변경이 아니라 새 보안등 자료와 관리기관 문의 준비 흐름을 추가했습니다.

## 실제 자료와 범위

- [전국보안등정보표준데이터](https://www.data.go.kr/data/15017320/standard.do)의 키 없는 공식 HTML 표 일부 **499행**을2026-10-29 UTC 수집했습니다. 모두 원문 지역명 **전남광주통합특별시 진도군**, 기준일 **2026-09-15**입니다. 전국 전체·진도군 전체·실시간 상태로 확대하지 않습니다.
- `scripts/snapshot_lighting.py`로 추출하며 `public/lighting-snapshot.json`에 수집시각·행 수·기준일·지역·원문 HTML SHA256·범위를 보존합니다. 같은 시설명/주소라도 조건이 다르면 보존하며 고유 ID는 보존 필드의 해시입니다. 위경도는 저장하지 않습니다.
- 위치명·주소·설치개수/연도/형태·관리기관/공개전화·기준일을 원문 그대로 사용합니다. 설치개수를 현재 켜진 등 수로 바꾸거나 설치연도로 노후/위험도를 판단하지 않습니다. 읍/면/동은 주소의 명시된 토큰만 사용하며 미확인 시 원문 확인으로 표시합니다.
- `public/lighting-api-guides.json`은 기존12,051 API 카탈로그의 세 서비스 메타데이터를 정확히 추출한 별도 공개자료입니다. 원래 카탈로그 수집시각과 이번 공식 문서 확인시각을 분리합니다. 시설 데이터·실시간 응답·가상 예시가 아닙니다.

향후 실제 확장 시 위 정확한 서비스의 최신 HTTPS 명세·기존 활용승인·응답 정상코드/스키마와 운영 어댑터 구현을 먼저 확인해야 합니다. 공공데이터포털 공통 `DATA_GO_KR_SERVICE_KEY`와 서비스별 활용승인은 별개이며 기존 기관별 override 호환성을 보존해야 합니다. 이번 화면을 위해 새 키/변수/권한을 등록할 필요는 없습니다. 새 기관 연결을 승인 없이 추가하거나 비밀값을 채팅에 보내면 안 됩니다.

원래 검토한 공중화장실/와이파이 표준자료는 공식 페이지가 외부 제공 시스템으로 이전돼 본 실행의 허용 호스트 안에서 실제 표를 얻지 못했습니다. 외부 호스트 연결이나 권한 확대를 시도하지 않았습니다. 보안등 공식 표로 범위를 확정했고 다른 서비스는 만들지 않았습니다.

## 개인정보·오류·보안

사용자 이름·연락처·사진·건강·위치·이동경로를 받지 않습니다. 검색과 필터·선택은 브라우저 메모리에만 두고 서버/기관에 전송하지 않습니다. 문의 참고정보는 공공시설 원문만의 readonly textarea이고 localStorage·쿠키·DB 저장/클립보드 권한·자동 발신·신고 전송 없음. 공식 문서 링크는 세 ID의 정확한 HTTPS 포털 URL만 허용하며 React 기본 이스케이프를 사용합니다. 전화 URL은 기존 검증을 재사용합니다. 환경변수·키·인증 URL을 브라우저에 넣지 않습니다.

스냅샷과 공식 연결 안내를 독립적으로 로드·검증해 하나가 실패해도 다른 자료를 보존합니다. 손상된 형식·연결 오류·빈 검색·API 미연결을 구분합니다. 다시 불러오기로 공개파일만 재요청하며 예시/미연결 수치를 만들지 않습니다. 기존 서버/API/Secrets/권한/유료 설정/공개범위/예약은 변경하지 않습니다.
