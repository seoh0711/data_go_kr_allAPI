## 사용자 문제와 핵심 outcome 하나

모임 장소를 알아보는 사람이 회의실/강의실의 공개 요금 기준·시간·수용인원·설비·신청방법을 비교해 문의할 후보를 정하고,조건 검토 후 준비서를 완성하는 과업이다. 모임 내용·참석자/단체명·날짜/시간·실제 위치·개인 연락처는 받지 않는다. 신청·예약·확정 요금·현재 빈자리/개방·수용 적합성을 판정하지 않는다. 스포츠 종목별 시설 검색과 달리 회의/강의 장소의 대관 문의 준비가 목적이다.

핵심 outcome: **두 장소의 공식 조건을 비교해 검토 표시가 있는 문의 준비서를 만들고,실수로 선택을 비웠을 때도 유효한 준비 상태를 복구한다.** 실제 문의/대관 성공은 미측정이다. 검색→조건 이해→비교→문의 후보 선택→검토→문의 준비→선택 실수 복구를 이번 범위로 정한다.

## 자료와 구현 전 측정 계획

이번 허용 경로 접근 확인에서 전국공공시설개방정보표준데이터15013117 공식 공개표 HTTP200,499행을 직접 확보했다. 이전503 이력은 보존하며 이번 정상 응답이 모든 공식문서/기관 복구를 뜻하지 않는다. 이 중 유형 원문이 회의실/강의실인69행만 추출할 계획이다. 같은 표의 체육시설/기타 유형을 모임 장소로 추정하지 않는다. 기존 혜택3기관 API는 별도 ‘공간/대관/회의/평생학습/주민’ 문구 안내로만 재사용하고 선택 시설의 지원/자격과 매칭하지 않는다.

직전 API 조합노트(981733f/배포f7c3d6ac)와 관련 운동한칸을 실제 운영에서 측정한다. 관련성은 공공시설의 요금·시간 원문을 보고 문의/이용 준비하는 과업 구조다. 개발자 준비와 장소 대관의 원시 초/클릭·성과를 직접 비교하지 않는다. 직전의 비교10그룹·검토3개·준비3/3·왕복0을 유지 품질로 삼고,선택 실수 복구를 추가 개선으로 검증한다.

모바일390×844·키보드만·기존API실패 주입 복귀 각1회,공개 고정 첫2개 API/시설을 사용한다. 직전은 준비서 생성→선택 비우기→앱 안의 되돌리기/검토·준비 복구 가능 여부를 실제 확인한다. 관련 서비스는 첫2시설의 이름/날짜·공식근거/시간·요금 원문/확인할 한계를 상세에서 확인한다. 기관 실패는 검증 브라우저 요청 차단으로만 주입하며 계룡시 등 보류API를 실제 호출하지 않는다.

지표: 필수 근거5그룹×2(10그룹),검토3개/준비 산출물 정확성,상세왕복·외부재구성,선택 비우기 뒤 원상복구 성공/3시도,복구 가능/범위/남은 검토의 키보드/모바일 표시. 실사용자 이해/절감시간·실제 대관·만족도는 미측정이다. 실제 관측 후 구현 전에 목표값을 다음 절에 확정하며 아직 개선 달성을 주장하지 않는다.
