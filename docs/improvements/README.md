# 회차별 개선 이력

[제작 기준](../service-development.md)에 따라 [템플릿](TEMPLATE.md)을 회차마다 복사해 누적한다. 과거 기록은 덮어써 달성으로 바꾸지 않는다. 날짜·서비스/버전·핵심 outcome·세 축 결과·증거 종류·다음 기준선·미달/차단을 연결한다. 수치가 없는 항목은 미측정,검증하지 않은 성과는 미검증으로 둔다.

|회차/기록|대상/버전|핵심 outcome|기능·UI/UX·과업 완료|증거 종류/한계|배포 / GitHub|다음 회차|
|---|---|---|---|---|---|---|
|[000 준비](000-baseline-plan.md)|농기계빌림길 `3f5ef03` 및 비교 후보 이동충전길|문의 준비 산출물 완성(측정 제안)|모두 미측정·미검증|소스/과거 문서 열람만,실제 과업 미실행|새 배포 없음 / 문서 커밋의 원격 확인은 작업 종료 보고 참조|실제 기준선 측정→목표 확정→구현|

실사용자 outcome 관측 기록: **현재 없음**. 과거 자동화 테스트·공개 운영 확인을 실제 사용자의 전환율·절감시간·만족도로 소급 해석하지 않는다.
