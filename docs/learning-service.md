# 배움길

기존 공개 데이터 아틀라스의 아홉 번째 생활 서비스. 경로 `/services/learning/`.

## 해결하는 문제

배우고 싶은 강좌의 교육방법·일정·수강료 원문을 비교하고, 교육 관련 공공서비스 안내를 별도로 살펴보는 탐색 서비스입니다. 강좌 상세에서 공공안내 화면으로 이동할 수 있지만 특정 강좌와 지원 제도의 연계·신청 가능·수급 자격·현재 접수·잔여 정원을 판단하지 않습니다. 강좌 공개표는 기존8개 서비스에 없던 새 자료이며 개인정보 기반 추천이나 기존 혜택 화면의 이름 변경이 아닙니다.

## 공식 공개자료

- [전국평생학습강좌표준데이터](https://www.data.go.kr/data/15013110/standard.do)
- 2026-10-28 UTC에 키 없이 공식 HTML 표 일부499행을 수집했습니다. 원자료 기준 **2026-06-30~2026-10-08**, 교육장 주소 기준 경기도·경상남도·경상북도·대구광역시 일부입니다. 전국 전체 목록이 아닙니다. 온라인32/오프라인467개라는 분포도 해당 공개표 일부의 표기입니다.
- `scripts/snapshot_learning.py`로 재현하며 `public/learning-courses.json`에 수집시각·기준일·지역/교육방법 분포·499행·원본 HTML SHA256·범위를 기록합니다.
- 강사명은 저장하지 않았습니다. 교육장/운영기관의 공개 주소·연락처와 강좌 설명·대상·방식·기간/시간/요일·정원·수강료·접수기간·방법·선정방법·홈페이지·기준일만 보존합니다. 개인 학습자·가족·소득·건강·미성년자 정보는 수집하지 않습니다.
- 접수기간을 현재 접수 가능 상태로, 정원을 잔여 자리로, 수강료0을 모든 비용 무료로 바꾸지 않습니다. 원문이 숫자만일 때0/양수 표기를 구분하고 복합/누락 금액은 원문 확인으로 표시합니다. 교육 시작월은 원문 날짜의 월이며 현재 모집 중이라는 뜻이 아닙니다. 과거 강좌가 포함될 수 있습니다.
- 교육장 주소의 시도/시군구는 원문 토큰을 사용합니다. 온라인 강좌도 교육장 주소로 분류하며 사용자 소재지/참여 가능 지역으로 확대하지 않습니다. 원문 홈페이지가 HTTPS로 확인되는 경우만 링크하고 다른 형식은 원문 텍스트로 남기며 임의로 프로토콜을 바꾸지 않습니다.

## 카탈로그 및 공식 제공기관 문서로 확인한 기존 API 조합

1. [행정안전부_대한민국 공공서비스(혜택) 정보 (15113968)](https://www.data.go.kr/data/15113968/openapi.do)
   - 기존 HTTPS `https://api.odcloud.kr/api/gov24/v3/serviceList`
   - 기존 serviceKey/page/perPage/returnType 요청과 JSON 파싱 재사용. 기관별 첫최대100건의 제목·목적요약·소관기관·상세URL·수정시각을 사용합니다.
2. [한국사회보장정보원_중앙부처복지서비스 (15090532)](https://www.data.go.kr/data/15090532/openapi.do)
   - 기존 HTTPS `https://apis.data.go.kr/B554287/NationalWelfareInformationsV001/NationalWelfarelistV001`
   - 기존 serviceKey/pageNo/numOfRows/callTp/srchKeyCode 요청과 XML 파싱·정상코드 검증 재사용.
3. [한국사회보장정보원_지자체복지서비스 (15108347)](https://www.data.go.kr/data/15108347/openapi.do)
   - 기존 HTTPS `https://apis.data.go.kr/B554287/LocalGovernmentWelfareInformations/LcgvWelfarelist`
   - 기존 serviceKey/pageNo/numOfRows 요청 및 실제 wantedList/servList 파싱 재사용.

실제12,051 API 목록과 공식 포털 상세 페이지를 다시 대조했습니다. 기존 API/인증/캐시/서버 어댑터는 수정하지 않고 `/api/benefits`를 그대로 사용합니다. 정부24의 포털 바깥 Swagger 호스트는 현재 허용 범위 밖이므로 새 접근을 시도하지 않습니다. 해당 연결은 기존 공식 명세 검증과 실제 정상 응답 계약을 유지합니다.

기관별 첫100건 내에서 제목·요약·기관명에 `교육/학습/수강/훈련/장학` 문구가 있는 기록만 브라우저에서 찾습니다. 공식 교육분류나 개인 자격으로 분류하지 않으며 선택한 강좌와 매칭하지 않습니다. 출처별 상태/수신시각을 구분하고 일부 기관 실패 시 정상 자료를 유지합니다. 기록의 수정일은 기관 원문이며 수신시각이나 최초 등록일로 바꾸지 않습니다. 화면에는 문구 검색 결과 첫100건을 표시하고 그 이상은 제공기관·검색어로 좁히도록 안내합니다. 전체 교육지원 제도 목록이 아닙니다.

## 인증·개인정보·보안

기존 공통 DATA_GO_KR_SERVICE_KEY와 기관별 기존 BENEFITS_GOV24_KEY/BENEFITS_CENTRAL_KEY/BENEFITS_LOCAL_KEY override 호환성을 그대로 사용합니다. 새 키 생성·등록·복사·Secrets 변경·새 지속접근·새 제공기관 권한은 없습니다. 문제 발생 시 위 정확한 API의 기존 활용승인·키 적용 상태를 공식 포털에서 확인하면 됩니다. 공통키 사용과 서비스별 활용승인은 별개입니다. 키 값은 채팅에 보낼 필요가 없습니다.

기관 조회는 버튼으로만 실행하며 `/api/benefits`에 사용자 쿼리를 붙이지 않습니다. 검색·강좌/지역/교육방법/시작월/수강료/기관 선택은 브라우저 메모리에만 있고 서버 전송·localStorage/쿠키/DB 저장은 없습니다. 나이·학력·소득·건강·가족정보 입력, 위치 권한, 가입·접수·결제 기능 없음. 강좌와 지원 자격·법률/금융 판단은 하지 않고 공식 원문 확인을 안내합니다.

기존10초 기관 요청 제한,2MiB JSON/XML 검사,외부 엔티티 거절,redirect 차단,비밀 반사 방어,정형 오류,성공 결과30분 캐시를 유지합니다. 브라우저 제한12초. 원문 오류·인증URL·키를 클라이언트에 보내지 않습니다. 기관 텍스트는 React 기본 이스케이프이며 외부 공식 링크는 기존 검증을 재사용합니다. 가상 예시와 미연결 수치는 없습니다.
