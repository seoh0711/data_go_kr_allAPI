# 기억돌봄창구

데이터 아틀라스의 열네 번째 생활 서비스. `/services/care/`.

## 해결하는 문제와 구현 범위

치매 관련 기관에 문의할 때 공개 주소·연락처·기관 유형을 찾고,관련 지원 안내를 별도로 확인하는 작은 탐색 서비스입니다. 기관명/주소/운영기관 검색,시도·시군구·기관 유형 필터,초기화/빈 결과/더 보기,상세/ESC/초점 복원,기관 상세→별도 공공안내 탭과 초점 이동,모바일 화면을 제공합니다. 기존 혜택 화면의 이름만 바꾼 것이 아니라 새 기관 연락처 자료와 문의처 탐색 흐름을 추가했습니다.

증상·진단·건강·가족·소득·개인 위치를 입력받지 않습니다. 특정 이용자의 진단·지원 자격·기관 이용 대상·진료/예약 가능 여부를 판단하지 않습니다. 기관 연락처와 제도를 연계/맞춤 추천하지 않고 공식 원문·기관 문의를 제공합니다.

## 실제 공개자료의 수집 방식과 한계

- [전국치매센터표준데이터](https://www.data.go.kr/data/15021138/standard.do) 공식 페이지를 공개 웹 읽기 도구로 열어 확인한 **일부16기록**입니다. 이 도구가 반환한 공식 페이지 텍스트425~440행의 기관명·유형·주소·운영기관·기관/관리기관 공개 연락처·관리기관·자료 기준일만 화이트리스트로 추출했습니다. 직원/센터장 성명·직원 수·좌표·의료활동/진료 설명은 보존하지 않았습니다. 환자나 사용자 정보가 아닙니다.
- 2026-10-29 UTC 수집,원자료 기준 **2026-03-04~2026-06-05**,원문 지역명9개 일부입니다. 전체 자료나 전국 전체·현재 운영·예약 가능 목록이 아닙니다. 원문 ‘전라남도’ 등 지역명은 임의 변경하지 않습니다.
- 직접 HTML 수집은 공식 www 호스트의 최초503와 한정 재확인503,동일 공식 data.go.kr 호스트503으로 실패했습니다. 인증·네트워크 권한 거부를 우회하거나 다른 실행 환경/프록시를 사용하지 않았습니다. 별도로 허용된 공개 웹 읽기 도구의 공식 문서 텍스트에서 위16기록만 확인했습니다. **직접 전체 원자료 다운로드가 성공했다고 주장하지 않습니다.** 웹 읽기의 캐시 가능성과 공개자료 기준일을 고려해 고정 스냅샷으로만 표시합니다.
- `public/care-centers.json`에 sourceMethod·원문행 범위·수집시각·자료 기준일·행 수·원문 지역 분포·보존 사실의 SHA256을 기록합니다. `scripts/snapshot_care.py --verified-rows <공식 텍스트에서 확인한 화이트리스트 JSON>`으로 재현합니다. 기존 출력의data를 입력으로 재포장할 수 있지만,그 자체가 원문 최신 재검증을 뜻하지 않습니다. 새 원문 검증 없이 최신 운영 상태로 표시하면 안 됩니다.
- 고유 ID는 보존된 공공기관 필드의 해시입니다. 주소의 명시된 시도·시군구 토큰만 사용하며 개인 소재지·거리·현장 접근 가능성으로 확대하지 않습니다. 시설 운영시간/진료/예약 상태는 자료에 추가하지 않습니다.
