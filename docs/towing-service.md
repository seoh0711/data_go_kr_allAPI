# 견인보관소 문의길잡이

운영 경로 `/services/towing/`. 보관소의 공개 요금/수용규모/문의처를 비교하고 **준비가 막힌 이유와 다음 보완 항목을 확인해 문의 준비서를 완성**합니다. 차량번호·소유자·차종을 조회하거나 실제 차량 위치·견인의 적법성·개별 적용요금/출고 자격을 판단하지 않습니다. 실제 연락·신고·출고 요청도 전송하지 않습니다.

## 공개자료와 현재 정보의 경계

[전국견인차량보관소표준데이터15021106](https://www.data.go.kr/data/15021106/standard.do)를2026-11-01 02:38 UTC에 HTTP200으로 확인했습니다. 공개표98행→98기록·지역 원문17종의 표본이며 기준일2017-05-18~2026-09-17입니다. **2017년 기준 기록도 포함**합니다. 전국 전체나 현재 시설 운영/관할·차량 보관 여부/빈자리·실제 적용요금 정보가 아닙니다.

보존 필드는 보관소명/주소·보관소전화·가능대수·견인기본/추가요금·보관료·관리기관명/관리기관전화·기준일입니다. 좌표/면적·차량번호/차대번호·소유자/차량종류·사용자 위치/연락처는 제외합니다. `public/towing.json`은 수집일·기준일·범위·원문SHA256을 가진 고정 스냅샷이며 스키마/열수/필수값/행수 검증 실패 시 추출기는 기존 파일을 바꾸지 않습니다.

지역 원문의 ‘계양구’처럼 불완전하거나 과거 행정명칭인 주소도 임의 정규화하지 않습니다. 보관가능200대를 현재 빈자리/보관차량200대로 바꾸지 않고,톤수·거리/시간별 요금 원문을 개인 차량의 실제 금액으로 계산하지 않습니다. 현재 안내와 연락처는 해당 기관의 최신 공식 안내를 확인해야 합니다.

## 기존 문의 준비 품질과 8단계 보완 안내

2후보×5정보그룹,기록ID/기준일/원문값에 묶인 선택근거,미확인 질문2개와 우선질문,공개 문의경로와 검토/문구 생성을 유지합니다. 보관소전화와 관리기관전화를 각 원문 기관명/번호로 구분합니다. 원문 경로·기록/날짜/기관/종류/값은 정확히 일치해야 준비할 수 있습니다. 실제 연결/소유자·현재 담당은 검증하지 않습니다. 전화 형식 오류/미제공은 경로 선택을 제한하고 공식 원문 확인 대안을 제공합니다.

준비 상태는 후보2·먼저 문의할 후보·선택근거·질문2·우선질문·문의경로·검토3·준비 문구의 **기존 요건8단계**를 표시합니다. 첫 미완료의 이유와 ‘다음 준비 항목으로 이동’으로 필요한 라디오/체크/생성 버튼에 초점만 옮깁니다. 자동 선택/체크·문구 생성·연락은 하지 않습니다. 가이드가 충족됐다는 표시는 앱 안의 준비 요건이지 실제 기관 확인/문의 완료가 아닙니다.

문의경로가 없으면 그 경로 입력으로,경로 선택 후 초기화된 검토는 해당 체크로,모든 요건을 채우면 생성 버튼으로 이동합니다. 공개표 오류는 재조회 버튼으로 복귀하고 빈 검색/숨겨진 후보는 검색 초기화로 돌아갑니다. 검색/지역/기재·미제공 필터·빈 결과·더보기와 키보드/모바일 초점 복귀를 제공합니다.

교체 중에는 기존 준비를 보존하되 문구 생성 단계를 완료로 표시하지 않고 교체 결정 영역을 먼저 안내합니다. 취소는 원래 준비/상태를 복구하고 확정은 변경된 근거/질문/우선/경로/검토를 다시 갖추게 합니다. 같은 자료 판본의 마지막1회 변경만 되돌리고 새로고침/자료 재수신/새판본에서는 보관하지 않습니다. 독립 공공안내 오류/미연결은 준비와 가이드를 보존합니다.

## API 조합과 비밀값 없는 연결 안내

12,051건 카탈로그의 기존3기관 `/api/benefits`를 재사용합니다. 제목/요약/기관명의 차량/교통 문구를 별도 공공안내로 찾으며 선택 보관소의 제휴·견인료 지원/개인 자격과 매칭하지 않습니다. 각 첫최대100건·성공 캐시 최대30분·화면 첫100건 범위이며 빈 결과는 전체 제도 부재가 아닙니다. 실제 수신/수정시각과 원문 표의 기준일을 구분합니다.

## 개인정보와 성과 한계

차량번호/차대번호·소유자/차량종류·개인 위치/건강·연락처를 입력받지 않습니다. 검색/선택/질문·우선/경로·검토·복구·문구는 화면 메모리에서만 처리하고 URL/서버/브라우저 저장소·외부 분석으로 보내지 않습니다. 준비 문구는 읽기 전용이고 기본 복사 기능만 사용합니다.

[회차009 기준선→목표→관측/검증](improvements/009-towing.md). 자동화 대리 과업은 실제 이용자의 문의/차량 출고 성공·이해·전환율·절감시간·만족도의 증거가 아닙니다. 실사용자 outcome은 미측정입니다.
