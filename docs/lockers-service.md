# 택배함찾기

기존 공개 데이터 아틀라스의 열한 번째 생활 서비스. 경로 `/services/lockers/`.

## 사용자 문제와 범위

택배 수령 전 시설의 위치·요일별 시간·사용방법·규격·요금 원문을 확인합니다. 운송장·휴대전화·수령 인증번호·보관함 비밀번호를 입력하거나 배송·수령을 처리하지 않습니다. 현재 빈 칸·고장·개방·수령 가능·물품 적합성·최종 요금을 계산하지 않습니다. 부산 시설은 같은 구·군의 주차 참고자료를 별도로 살펴볼 수 있으며 인근/전용/할인 관계로 연결하지 않습니다.

핵심은 기존 시장/주차 서비스의 이름 변경이 아니라 **택배함 수령정보를 받지 않는 시설 이용조건·요일별 시간·코드형 칸 규격·무료/연체 조건 확인**입니다. 새 공개자료와 해당 상세 흐름을 추가하고 기존 두 주차 API는 승인된 연결 그대로 재사용합니다.
