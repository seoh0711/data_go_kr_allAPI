# 주차돋보기

> 운영 상태 갱신: 사용자가 공통 키를 직접 등록했고 실제 API 수신을 확인했습니다. 아래의 초기 미등록/미검증 기록과 현재 상태는 [최신 연결 검증](live-connection-verification.md)을 구분해 보세요.

기존 데이터 아틀라스의 네 번째 생활 서비스입니다. 경로는 `/services/parking/`이며, 출근나침반·혜택모아·문화쉼표와 12,051건 카탈로그를 보존합니다. 주차 조건을 확인하는 데 집중하며 요금 결제·총액 계산·입차 예약·현재 빈자리 보장은 제공하지 않습니다.

## 실제 공개 스냅샷

공식 [전국주차장정보표준데이터](https://www.data.go.kr/data/15012896/standard.do)의 공개 HTML 표에서 공영으로 표기된 **499건**을 수집했습니다. 수집 시각은 **2026-10-27 05:40 KST**, 원문 자료 기준일은 **2026-07-29 ~ 2026-10-01**입니다.

- 공식 공개표 일부이며 전국 전체 공영주차장 목록이 아닙니다. 현재 공개표는 3개 원문 표기 지역에 편중되어 있습니다. 검색 결과가 없어도 해당 지역에 주차장이 없다는 뜻이 아닙니다.
- 공개표의 공영 구분·유형·주소·구획수·요금·요일/시간·결제방법·특기사항·관리기관·전화·기준일만 선택했습니다. 원문 위경도, 개인 위치, 차량번호, 이용자 개인정보는 수집하지 않습니다.
- 지역 필터는 원문 주소의 첫 단어를 사용하며, 현재 행정구역 명칭으로 추정해 고치거나 외부 위치 서비스에 보내지 않습니다.
- 원문 요금 구분은 무료 433건, 유료 58건, 혼합 8건입니다. 이는 기준일의 자료 분포이며 현재 모든 시간·차종의 무료 여부를 뜻하지 않습니다. 0원·결측 기본요금만으로 무료를 추론하지 않습니다.
- 기본시간/요금, 추가 단위시간/요금, 일일 적용시간/요금, 월정기 요금을 원문 조건별로 표시합니다. 서로 다른 시간 단위의 요금을 싼 순으로 정렬하거나 할인·상한·야간 이월·법정 요금을 계산하지 않습니다.
- 구획수는 전체 시설 규모이며 잔여 대수가 아닙니다. 정적 자료에는 `remaining=null`과 `observedAt=null`을 유지합니다. 동일한 시작·종료 시각, 결측 시간은 운영시간 확인 필요입니다. 24:00과 H:mm 원문은 그대로 표시합니다. 공휴일 시간은 일요일 시간으로 바꾸지 않습니다.

공식 페이지의 기본 조회가 일시적인 503 연결 시간 초과를 반환해, 같은 공식 사이트에서 공개 UI의 검색 경로를 사용했습니다. 접근 제한 우회나 다른 환경은 사용하지 않았습니다. 재현 URL은 `public/parking-snapshot.json`의 `metadata.publicQueryUrl`에 기록했습니다. 이는 공공시설 검색 조건이며 개인 검색어가 아닙니다.

```sh
python3 scripts/snapshot_parking.py
python3 scripts/snapshot_parking.py --html /absolute/path/to/public-page.html
```

수집기는 공개 표 헤더·열 수·500건 상한·공영 여부·필수 필드·날짜·고유 ID를 검증하고 성공 시에만 JSON을 교체합니다. 공개 HTML 원본과 명세 캡처는 체크아웃 밖 `/workspace/parking-research/`에 있고 배포하지 않습니다. 공개 JSON에는 출처 URL·수집 시각·원본 SHA-256·범위를 기록했습니다. 자동 갱신·새 예약은 만들지 않았습니다.

## 기존 API 목록에서 조합한 두 서비스

공식 포털 페이지, 부산광역시 항목별 명세와 부산시설공단의 내장 Swagger를 읽었습니다. 두 API는 REST, JSON+XML, API 이용 비용 무료, 개발/운영 자동승인으로 표시되며 서비스별 활용 신청이 필요합니다. API 무료와 주차장 무료는 별개입니다.

| 출처 | 목록 경로 | 요청 | 선택적 우선 변수 |
| --- | --- | --- | --- |
| [15004683 부산광역시_공영주차장 정보 조회](https://www.data.go.kr/data/15004683/openapi.do) | `https://apis.data.go.kr/6260000/BusanPblcPrkngInfoService/getPblcPrkngInfo` | `ServiceKey`(대문자 S), `pageNo=1`, `numOfRows=20`, `resultType=json` | `PARKING_BUSAN_KEY` |
| [15157490 부산시설공단_공영주차장 시설 현황 조회 서비스](https://www.data.go.kr/data/15157490/openapi.do) | `https://apis.data.go.kr/B552587/ParkingInfoService_v2/getParkingInfoList_v2` | `serviceKey`, `pageNo=1`, `numOfRows=20`, `resultType=json`; 선택 코드 `pParkGCd`는 전송하지 않음 | `PARKING_AVAILABILITY_KEY` |

두 서비스 모두 공통 `DATA_GO_KR_SERVICE_KEY` fallback을 사용합니다. 위 기관별 변수는 선택적 우선 설정이며 별도 키 발급이 필수라는 뜻이 아닙니다. 별도 인증체계의 서울 열린데이터광장 키 등은 사용하지 않습니다.

부산광역시 안내는 `pkNam`, `pkCnt`, `pkBascTime`, `tenMin`(공식 정의: 주차기본요금), `pkAddTime`, `feeAdd` 등의 원문 필드로 정규화합니다. `currava`의 설명은 ‘실시간주차면수’이므로 이를 잔여 대수로 해석하지 않고 표시에서 제외했습니다.

부산시설공단 명세는 `parkingcnt`를 점유 중 대수, `maxcnt`를 최대 대수, `curravacnt`를 갱신시각 기준 가능 대수, `lastupdatetime`을 최종 갱신일시로 정의합니다. **가능 대수는 `curravacnt`만** 사용합니다. 점유 대수나 전체 구획수를 잔여로 오인하거나 빼기로 추정하지 않습니다. 0대는 0대로 유지하며, 결측·음수·최대 초과는 미제공으로 표시합니다. 기관 갱신시각 원문과 서버 수신 시각(KST)을 구분하고 현재 입차를 보장하지 않습니다. API 목록에 없는 주소·요금은 생성하지 않습니다.

공개표·부산광역시·부산시설공단은 별도 탭이며 이름만으로 서로 다른 시설을 결합하거나 중복 합산하지 않습니다. 기관별 첫 20건 이내만 표시합니다.

## 연결·보안·운영 범위

이번 실행에서는 인증된 기관 API 호출, 키 전송·복사·등록, 권한 변경을 하지 않았습니다. 현재 실행 환경은 `apis.data.go.kr`를 네트워크/키 사용 대상으로 허용하지 않으며 운영 공통 키는 사용자 직접 등록 대기입니다. 이전 전달 차단을 재시도하지 않았습니다. 실제 기관 인증·활용 승인·응답 구조는 운영 연결 후 추가 검증해야 합니다.

`/api/parking`은 API 탭 최초 진입과 명시적 다시 조회만 사용합니다. 자동 반복 조회는 없습니다. 안내는 최대 15분, 가능 대수는 최대 1분, 전체 응답은 30초 캐시될 수 있습니다. 서버 수신 시각이 최신이어도 기관 자료가 최신임을 뜻하지 않습니다.

검색·지역·요금/유형 필터·후보 목록은 브라우저 메모리에서만 사용하며 새로고침 시 초기화됩니다. 위치 권한·차량번호·결제정보를 요청하지 않습니다. 서버의 쿼리 인수는 전부 400으로 거부합니다. 외부 지도/광고/사진을 자동 로드하지 않습니다.

기관별 미연결·정상·빈 응답·오류를 구분하고 일부 실패가 다른 자료를 없애지 않습니다. 가상 주차장·잔여 대수 예시는 제공하지 않습니다. 응답 2 MiB 제한·10초 제한·고정 제공기관 주소·리디렉션 거부·XML DOCTYPE/ENTITY 금지·정규화 필드 선택·반사된 인증키 폐기·안전한 기관 전화 링크를 적용했습니다. 인증 URL·원문 응답·비밀값을 로그/파일/채팅에 출력하지 않습니다.

## 검증

공개표 정합성·범위·고유 ID·원문 요금 분류, 검색/지역/유형/요금/후보/초기화/더 보기, 0원과 무료 분리, 총/점유/가능 대수 구분, 결측/0/음수/최대 초과, 공통 키/우선 설정/대문자 ServiceKey, 부분 장애/빈 응답/캐시/비밀값 반사/XML 공격/큰 응답/잘못된 쿼리, 모바일/키보드/모달/연락처/입력 미전송·미저장/위치 미요청을 테스트합니다. 기존 아틀라스와 세 서비스 회귀도 포함합니다. 자동 테스트의 기관 응답은 모의 응답이며 인증된 운영 데이터 검증을 대체하지 않습니다.
