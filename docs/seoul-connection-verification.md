## 실제 API 확인

사용자 경로를 저장하거나 추정하지 않고 서울역·강남역을 테스트 입력으로 각 1회 조회했습니다.

- 강남역: 서버 확인시각 `2026-10-26T23:38:28.730Z` (한국시간 08:38:28), 같은 요청 단계 timeout.
- 두 경우 모두 제공기관의 HTTP 응답·성공 코드·도착 행·기관 기준시각을 받지 못했습니다. 앱 서버의 HTTP 200은 서울 API 성공이 아닙니다.
- 따라서 키 유효성, 활용 승인, 빈 결과, 기관 응답 형식, 기관 장애 여부는 확인되지 않았습니다. 등록된 키가 잘못됐다고 판단하지 않습니다.
- 현재 설정된 공식 호스트 `swopenapi.seoul.go.kr`의 HTTPS 접속 시간 초과입니다. HTTPS 주소/포트 지원 문제인지 기관 연결/접근 제한인지 추가 확인이 필요합니다. TLS를 끄거나 키를 평문 HTTP·다른 호스트로 전달하지 않았습니다.

사용자는 키를 채팅에 다시 보낼 필요가 없습니다. 버스는 별도 문제로 9자리 관심 정류소 ID가 미설정이며 임의 ID를 저장하지 않았습니다.

## 추가 공개 문서 진단

공개 웹 조회 도구로 아래 서울시 공식 문서를 인증정보 없이 확인했습니다. 실행 환경의 네트워크 허용 목록을 변경하거나 다른 실행 환경을 사용하지 않았습니다.

- [해당 API 공식 명세](https://data.seoul.go.kr/dataList/openApiView.do?infId=OA-12764&srvType=A): 샘플 주소는 `http://swopenAPI.seoul.go.kr/api/subway/(인증키)/xml/realtimeStationArrival/0/5/서울`입니다. 명시 포트가 없으므로 HTTP 기본 포트 80이며, 현재 코드의 HTTPS 기본 포트 443과 프로토콜이 다릅니다. 호스트·서비스명·경로 형식·JSON 지원은 명세와 일치합니다.
- [공식 데이터셋 안내](https://data.seoul.go.kr/dataList/OA-12764/A/1/datasetView.do): 공개 sample은 `서울`역만 조회할 수 있고, `recptnDt`는 데이터 생성시각이며 지연될 수 있습니다. 담당 연락처는 02-2133-4969입니다.
- [공식 이용안내](https://data.seoul.go.kr/together/guide/useGuide.do): 일반 인증과 실시간 지하철 인증을 구분합니다. 따라서 공공데이터포털 공통키로 서울 키를 대체하지 않습니다.

해당 명세에는 HTTPS 주소·TLS 포트가 안내되어 있지 않습니다. 공식 사이트의 HTTPS/SSL 관련 검색에서도 이 서비스의 공식 HTTPS 대안을 확인하지 못했습니다. 이것만으로 서울시가 HTTPS를 전혀 지원하지 않는다고 단정할 수는 없습니다.

추가 연결 확인은 키가 없는 `https://swopenapi.seoul.go.kr/`와 같은 호스트의 공개 sample HTTPS 경로 각 1회로 제한했습니다. 공개 웹 도구는 두 주소 모두 `not accessible via this tool`을 반환했습니다. 이 결과는 TCP/TLS 원인을 구별하는 검사나 Cloudflare 발신 연결 검사가 아니므로, 포트 차단·TLS 미지원·기관 장애 중 하나로 확정하지 않습니다. 앞선 운영 서버의 두 요청은 HTTPS 443에서 응답 전 8초 제한에 도달했다는 사실만 확인합니다.

공식적으로 확인된 안전한 HTTPS 대체 경로가 없어 키를 포함한 추가 호출과 코드·운영 설정 변경·재배포는 하지 않았습니다. HTTP로 낮추거나 인증서 검증을 해제하거나 제3자 프록시로 키를 전송하지 않았습니다. Cloudflare의 일반 프록시 수신 포트 목록을 이 API의 발신 제한 근거로 사용하지 않았습니다.

남은 최소 조치는 서울시 담당자에게 이 서비스의 공식 HTTPS URL/포트와 Cloudflare 서버 발신 허용 여부를 확인하는 것입니다. 새 키 발급이나 재등록으로 해결된다고 판단할 근거는 없습니다. HTTPS 지원이 확인될 때까지 지하철은 미연결 상태로 유지하며 기존 9개 데이터 연결은 보존합니다. 이번 추가 진단은 문서만 변경했으므로 새 동작 테스트·재배포는 실행하지 않았습니다. 아래 테스트·배포 검증은 앞선 운영 키 반영 시 실행한 결과입니다.
