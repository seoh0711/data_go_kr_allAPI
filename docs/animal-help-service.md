# 동물문의길

기존 데이터 아틀라스의 열다섯 번째 생활 서비스. `/services/animal-help/`.

## 사용자 문제와 구현

야생동물 구조센터의 공개 연락처·주소·운영시간/휴무일 원문을 찾고 동물 관련 공공안내를 별도로 확인합니다. 센터명/주소/센터기능 원문 검색,시도·시군구·휴무일 표기 필터,초기화/빈 결과/더 보기,키보드 상세/ESC/초점복원,센터→별도 공공안내 탭과 초점 이동,모바일 화면을 제공합니다. 기존 기관/관광/공원 서비스의 이름 변경이 아니라 새로운 야생동물 센터 자료와 공개 운영조건·문의처 탐색을 추가했습니다.

개인의 발견 위치·사진·동물등록번호·소유자 연락처를 입력받지 않습니다. 신고/구조요청 접수·자동 발신·현재 출동/진료 접수/입소/동물별 대응 가능·동물 취급/치료 방법을 제공하거나 추정하지 않습니다. 관할·현재 운영·대응 범위는 센터 문의로 확인합니다.
