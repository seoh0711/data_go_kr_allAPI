# 다시쓰는센터

아틀라스의 열일곱 번째 서비스. [운영 화면](https://data-go-kr-api-atlas.pages.dev/services/reuse-centers/).

## 해결할 과업

물건을 취급하는 센터 후보를 검색하고 두 곳의 공개 연락처·기준일·품목/시간 원문·현재 확인할 조건을 같은 화면에서 비교합니다. 문의 후보를 명시적으로 선택하면 두 후보의 근거와 질문이 포함된 읽기 전용 메모를 만듭니다. 검색→이해→비교→선택→문의 준비까지 제공하며 연락·거래·수거·신청을 접수하지 않습니다. 기존 분리배출 길잡이의 봉투 가격/배출방법 탐색과 다른 과업입니다.

지역·품목 문구 필터, 검색·초기화·빈 결과·더 보기, 두 후보 선택/해제·전체 비우기, 선택 변경 시 이전 메모 무효화, 키보드 비교 제목/메모 초점 이동을 제공합니다. 검색 초기화와 공공안내 실패는 비교 선택을 보존합니다. 개인 주소·사진·품목 사진·실제 사례·연락처를 입력받지 않습니다. 선택·검색·메모는 메모리에서만 유지하며 서버·브라우저 저장소·분석 도구로 보내지 않습니다.

## 출처와 범위

[전국재활용센터표준데이터 15021108](https://www.data.go.kr/data/15021108/standard.do)의 인증 없는 공식 HTML 공개표를 2026-10-30 02:55 UTC에 수집했습니다. 185행 중 보존 필드가 완전히 같은 1행을 합쳐 **184기록**을 제공합니다. 기준일은 **2018-05-15~2026-09-17**, 주소 앞 토큰 기준 지역은 18종입니다. 전국 전체·184개의 고유 시설·현재 운영 상태로 단정하지 않습니다. 원문 지역 ‘강원도’ 및 오기 ‘서을특별시’도 임의 보정하지 않습니다.

`scripts/snapshot_reuse_centers.py --html <공식 HTML 경로>`로 재현합니다. 수집시각·기준일·범위·원문 해시는 `public/reuse-centers.json`에 있습니다. 공개 기관명·연락처·주소·취급품목·운영구분/기관·시간/휴무일·A/S 원문·관리기관·기준일만 보존합니다. 대표자명·위경도·차량 수·개인 식별정보는 보존하지 않습니다. 첫 조회의 연결 오류 후 한정 재확인에서 공식 HTML 200과 스키마/행을 확인했습니다. 별도 검색 도구의 문서 표현은 지원 형식 오류가 있어 실제 수집 HTML을 근거로 삼았습니다.

선별장 등 서로 다른 시설이 함께 있습니다. 취급품목에 ‘가전/가구’가 있다고 중고 매입·판매·방문 수거가 가능하다는 뜻은 아닙니다. 운영시간·A/S는 기준일의 원문이며 현재 개방·보증이 아닙니다. 시작/종료시각이 같아도 휴무/24시간으로 해석하지 않습니다. 누락은 미제공으로 표시하고 현재 조건·비용은 기관 확인 질문으로 남깁니다.

## API 조합과 설정

12,051건 실제 카탈로그의 기존 세 API를 `/api/benefits`에서 재사용합니다. 새 외부 인증 목적지·서버 어댑터·키를 추가하지 않습니다.

|제공기관 서비스/공식 문서|기존 HTTPS 경로|수신 범위|
|---|---|---|
|[행정안전부_대한민국 공공서비스(혜택) 정보 15113968](https://www.data.go.kr/data/15113968/openapi.do)|`https://api.odcloud.kr/api/gov24/v3/serviceList`|JSON 첫 최대100건|
|[한국사회보장정보원_중앙부처복지서비스 15090532](https://www.data.go.kr/data/15090532/openapi.do)|`https://apis.data.go.kr/B554287/NationalWelfareInformationsV001/NationalWelfarelistV001`|XML 첫 최대100건|
|[한국사회보장정보원_지자체복지서비스 15108347](https://www.data.go.kr/data/15108347/openapi.do)|`https://apis.data.go.kr/B554287/LocalGovernmentWelfareInformations/LcgvWelfarelist`|XML 첫 최대100건|

제목·요약·기관명에 재사용/재활용/중고/가전 문구가 있는 안내를 브라우저에서 찾습니다. 센터와의 제휴·수거 지원·개인 수급 자격을 매칭하지 않습니다. 첫 수신 범위에 없으면 빈 결과이며 제도가 없다는 뜻은 아닙니다. 기관 수정일 원문, KST 수신시각, 성공 자료 최대30분 캐시를 구분합니다. 미연결·빈 결과·부분/전체 실패를 구분하고 비교 과업과 독립적으로 복귀합니다. 가상 안내는 표시하지 않습니다.

기존 운영 `DATA_GO_KR_SERVICE_KEY` fallback과 기관별 `BENEFITS_GOV24_KEY`/`BENEFITS_CENTRAL_KEY`/`BENEFITS_LOCAL_KEY` override를 그대로 사용합니다. 공통 키와 서비스별 활용승인은 별개입니다. 오류 시 위 공식 서비스의 기존 활용승인과 운영 적용 상태를 확인해야 하며 이번 회차는 Secrets·권한을 변경하지 않습니다. 서울 HTTPS 차단, 계룡시 및 분리배출 API 인증 제약을 재호출하거나 우회하지 않았습니다.

## Outcome와 검증

구현 전 실제 농기계빌림길·분리배출 길잡이를 각3조건에서 측정하고 세 축 목표를 고정했습니다. 측정 프로토콜·원래 목표·실패/재시도·최종 검증·게시 및 GitHub 상태는 [회차 기록](improvements/001-reuse-centers.md), 검토한 수치는 [기준선](improvements/evidence/001-baseline.json)과 회차 증거 파일을 확인하세요. 자동화 대리 과업은 실제 사용자의 문의/거래 완료·절감시간·만족도를 증명하지 않습니다. 실사용자 outcome은 미측정입니다.
