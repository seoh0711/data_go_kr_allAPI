# 공원한바퀴

기존 공개 데이터 아틀라스의 일곱 번째 서비스. 화면 `/services/parks/`, 서버 `/api/parks?city=suwon`.

## 목적과 공식 자료

공원 시설을 검색하고, 외출 전 선택한 지역의 기상·대기 관측자료를 별도로 참고하는 작은 서비스입니다. 공원 현장 관측·경로·안전 점수·현재 개방 여부·건강상 권고는 계산하지 않습니다.

### 실제 공개 스냅샷

- [전국도시공원정보표준데이터](https://www.data.go.kr/data/15012890/standard.do), 공식 공개 표 조회 주소 `https://www.data.go.kr/tcs/dss/selectStdDataDetailView.do?publicDataPk=15012890`.
- 2026-10-27 14:44 UTC에 키 없이 공개 HTML 표 일부 499행을 수집했습니다. 원자료 기준 **2026-07-31~2026-09-16**. 6개 표기 시도의 일부 기록이며 전국 전체 목록이 아닙니다. 원문의 행정구역 표기를 유지합니다.
- 자료: `public/parks-snapshot.json`, 재현 스크립트: `scripts/snapshot_parks.py`. 수집시각·HTML SHA256·기준일 범위·수집 행 수·범위를 기록합니다. 499개 고유 ID이며 관리번호/명칭/주소로 중복 ID를 방지합니다.
- 면적과 운동·유희·편익·교양·기타시설 원문을 보존합니다. 시설 필터는 실제 기재된 정보만 사용하고 빈 칸/없음/0/미제공을 시설 보유나 현재 운영으로 해석하지 않습니다. 시설의 접근성·유료 여부·이용 가능 시간은 추정하지 않습니다.

### 이미 연결된 API 두 개 재사용

실제 12,051개 API 카탈로그 및 공식 제공기관 명세를 대조했습니다. 새 제공기관·인증 목적지·키·권한은 추가하지 않았습니다.

1. [기상청_단기예보 조회서비스 (15084084)](https://www.data.go.kr/data/15084084/openapi.do)
   - 초단기실황 HTTPS `https://apis.data.go.kr/1360000/VilageFcstInfoService_2.0/getUltraSrtNcst`
   - 기존 어댑터의 `serviceKey/base_date/base_time/nx/ny/dataType/numOfRows/pageNo` 요청과 관측 기준시각 계산을 재사용합니다. T1H/RN1/WSD를 기온/1시간 강수량/풍속으로 표시합니다. 예보나 공원 현장 측정값이 아닙니다.
2. [한국환경공단_에어코리아_대기오염정보 (15073861)](https://www.data.go.kr/data/15073861/openapi.do)
   - 측정소별 실시간 측정정보 HTTPS `https://apis.data.go.kr/B552584/ArpltnInforInqireSvc/getMsrstnAcctoRltmMesureDnsty`
   - 기존 어댑터의 `serviceKey/stationName/dataTerm/ver/returnType/numOfRows/pageNo` 요청을 재사용합니다. PM2.5/PM10과 기관 `dataTime`을 표시합니다. 결측·음수 농도는 미제공으로 처리하고 유효한 0은 보존합니다.

관측 지역은 기존 승인된 수원(대기: 신풍동)·성남(수진동)·고양(주엽동)·용인(김량장동) 네 곳만 지원합니다. 기상은 기존 지역 기준 격자입니다. 공원 검색 지역/선택 공원과 자동 연결하지 않고, 사용자가 관측 참고 지역을 따로 고르도록 했습니다. 다른 지역이나 공원 현장의 수치로 확대하지 않습니다. 관측시각과 서버 수신시각을 구분합니다.

## 인증·서버·개인정보

`functions/api/parks.js`는 기존 `buildFeed`에 공통 `DATA_GO_KR_SERVICE_KEY`와 기존 override `KMA_SERVICE_KEY`/`AIRKOREA_SERVICE_KEY`만 선별해 전달하고 weather/air만 반환합니다. **SEOUL_SUBWAY_KEY/GYEONGGI_BUS_KEY 및 다른 제공기관 키는 전달하지 않습니다.** 버스 정류소도 전달하지 않습니다. 공통키가 있어도 서울 auth에는 fallback하지 않고 버스는 정류소 없이는 호출하지 않는 기존 계약에 따라, 이 경로는 두 관측 API만 호출합니다. 단위 테스트가 실제 호출 호스트·경로·횟수·자격증명 격리를 검증합니다.

서버는 city 한 개만 받으며 네 지역 외 입력, 중복·주소·좌표·정류소·목적지 쿼리는 인증 호출 전 400으로 거절합니다. 개인 위치·자유 입력·검색 조건을 기관에 보내지 않습니다. 새 Secrets·설정·계정·지속 접근·비용·권한을 만들지 않습니다. 기존 두 API의 활용승인과 공통키/기존 override 설정은 유지합니다. 만약 인증·승인 오류가 발생하면 사용자가 위 정확한 서비스의 기존 활용승인 상태를 포털에서 확인하면 되며 키 값을 채팅에 보낼 필요는 없습니다.

기존 요청별 8초 제한·2MiB JSON/XML 응답 검사·DOCTYPE/ENTITY 거절·리디렉션 차단·비밀값 반사 방어·정형 오류만 노출하는 정책을 유지합니다. 브라우저 제한12초, HTTP 캐시 최대2분. 관측은 버튼으로만 조회하며 자동 반복 호출하지 않습니다. 부분 실패·빈 결과·키 없음·연결 실패 상태를 구분하고 정상 수신 관측과 공개표는 유지합니다.

검색·시도·시군구·시설 조건·선택 공원·관측 참고 지역은 브라우저 메모리에서만 처리합니다. localStorage/쿠키/DB 저장, 위치 권한·주소·건강·가족정보 입력 없음. 기관의 공개 문의전화만 검증된 tel 링크로 표시합니다. 원문 문자열은 React 기본 이스케이프로 렌더링합니다.
