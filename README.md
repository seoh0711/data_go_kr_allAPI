# 데이터 아틀라스

공공데이터포털 전체 오픈API를 16개 분야로 탐색하는 React/Vite 웹앱입니다.

## 실제 데이터

`public/catalog.json`에 공식 API에서 수집한 전체 목록을 저장합니다. 브라우저는 이 파일을 자동으로 읽으며 인증키가 필요하지 않습니다. 새로고침해도 공식 목록을 다시 불러옵니다. JSON 가져오기는 현재 탭에서만 적용되는 별도 기능입니다.

2026-10-26 수집 결과:

- 공식 `dataset`의 `list_type=OPEN API`: **12,051건**
- 전체 페이지 수집: 13페이지, 목록 ID 중복 0건, 삭제 제외 0건
- `open-data-list`: 17,082행, 18페이지. 목록별로 결합해 12,051개 전체의 기능 정보를 연결
- 분류: 공식 `new_category_nm`을 사용, 16개 분야 합계 12,051건

사용자 제공 초기 기준 12,012건에 맞춰 잘라내지 않고, 실제 조회된 전체 건수를 표시합니다. 웹앱은 수집 시점의 스냅샷을 제공하며 실시간 API 호출이나 자동 정기 갱신 서비스는 아닙니다. 카테고리 타일 면적은 비율을 나타내지 않습니다. JSON/XML 동시 지원은 `formats`에 보존하고 기본 형식 필터는 JSON 우선으로 표시합니다.

## 실행 및 검증

Node.js 22.12+ 또는 24, 갱신에는 Python 3 표준 라이브러리를 사용합니다.

```sh
cd /workspace/data_go_kr_allAPI
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
npm run build
npm test
npm exec --cache /workspace/.npm-cache -- playwright test
```

브라우저 테스트는 기본 `/usr/bin/chromium`을 사용하며 `CHROMIUM_PATH`로 변경할 수 있습니다. 테스트는 공식 목록의 전체 건수·고유 ID·카테고리 합계·기능 정보 연결과 실제 브라우저 검색·필터·즐겨찾기·가져오기를 검증합니다.

## 목록 갱신

환경 설정의 비밀값 `DATA_GO_KR_SERVICE_KEY`와 HTTPS 대상 `api.odcloud.kr`을 사용합니다. 키는 서버의 수집 명령과 Pages Functions에서만 사용하며 VITE_ 변수, 소스, 브라우저 요청에 넣지 마세요.

```sh
npm run sync:catalog
npm test
npm run build
```

공식 경로:

- `https://api.odcloud.kr/api/15077093/v1/dataset` + `cond[list_type::EQ]=OPEN API`
- `https://api.odcloud.kr/api/15077093/v1/open-data-list`

수집기는 페이지별 1,000행을 순차 조회합니다. 응답 페이지·행 수·전체 건수를 확인하고 목록 ID로 기능 정보를 결합합니다. 페이지 사이 총건수가 바뀌거나 수집이 실패하면 기존 공개 파일을 유지합니다. 원본 응답은 체크아웃 밖 `/workspace/atlas-cache`에 보관합니다. 성공한 결과만 `public/catalog.json`으로 교체합니다. 갱신 작업은 수동 실행이며 이용 트래픽 한도에 주의하세요.

## 탐색 기능

카테고리 맵/목록, 통합 검색, 형식 필터, 가나다순 정렬, 카드/리스트, 더 보기, 브라우저 저장 즐겨찾기, 상세 보기, 공식 상세 페이지 연결, JSON 가져오기, 모바일 메뉴와 Ctrl/Cmd+K 검색을 제공합니다.

가져오기 JSON은 배열이며 `id`, `title`, `category`, `organization`, `description`, `format`, `url`, `tags`가 필요합니다. category는 16개 분야, format은 JSON/XML/CSV/기타, url은 data.go.kr의 HTTPS 주소여야 합니다. 최대 30MB / 100,000개 항목입니다. 예제는 이용 가이드에서 다운로드할 수 있습니다.

이 앱은 공공데이터포털 공식 서비스가 아닙니다. 개별 API 실행과 활용 신청은 해당 제공기관 및 포털에서 진행합니다.

## Cloudflare Pages 배포

프로젝트 이름은 `data-go-kr-api-atlas`, 프로덕션 브랜치는 `main`, 업로드 대상은 `dist/`입니다. `npm run deploy`는 빌드 후 파일 크기와 비밀값 포함 여부를 검사하고, Pages 프로젝트를 생성 또는 재사용하여 업로드합니다. 성공 시 Wrangler가 실제 배포 URL을 출력합니다.

Cloudflare API 토큰은 환경 설정의 `CLOUDFLARE_API_TOKEN` 비밀값으로 입력하세요. 대상 계정에 **Account → Cloudflare Pages → Edit**, 계정 자동 확인을 위한 **Account → Account Settings → Read** 권한이 필요합니다. 하나의 계정으로 범위를 제한하세요. 계정이 여러 개면 공개 식별자인 `CLOUDFLARE_ACCOUNT_ID`도 설정합니다. HTTPS `api.cloudflare.com`과 배포 검증을 위한 `*.pages.dev` 접속이 필요합니다.

```sh
npm run deploy
```

토큰이나 데이터 조회키는 Cloudflare Pages의 브라우저 환경변수에 추가하지 않습니다. 배포는 저장된 전체 목록 스냅샷을 포함합니다. 이후 목록을 갱신하려면 `npm run sync:catalog` 후 다시 배포합니다.

## 생활 서비스: 출근나침반

기존 아틀라스의 `/services/commute/`에 경기–서울 출퇴근 서비스를 제공합니다. 홈 배너와 메뉴에서 이동할 수 있습니다. 수원·성남·고양·용인 출발, 서울역·강남·여의도 도착을 선택하고, 도착 희망 시각·평소 이동·도보·여유 시간을 브라우저에 저장합니다. 출발 권장 시각은 사용자 입력 기준이며 길찾기나 실시간 도착 예측이 아닙니다.

공식 카탈로그에서 선택한 API 네 개:

- `15080346` 경기도 버스도착정보 조회: 사용자가 설정한 9자리 정류소 ID의 버스 도착 정보
- `15058052` 서울특별시 지하철 실시간 도착정보: 서울 도착역의 열차 도착 정보
- `15084084` 기상청 단기예보 조회서비스: 출발 지역 대표 격자의 초단기실황
- `15073861` 한국환경공단 에어코리아 대기오염정보: 출발 지역 지정 측정소 대기질

`functions/api/commute.js`는 Cloudflare Pages Functions로 배포됩니다. `/api/commute`가 네 기관을 개별 조회하며, 화면이 열린 동안 60초마다 갱신합니다. 서버 응답은 30초간 캐시합니다.

경기도 버스·기상청·에어코리아와 혜택모아의 세 공공데이터포털 API는 **공통 `DATA_GO_KR_SERVICE_KEY` 하나**를 기본으로 사용합니다. 서비스별 활용 승인은 별도로 필요하며, 환경변수 이름이 여러 개라고 별도 키를 발급받아야 한다는 뜻은 아닙니다. 기존 기관별 변수는 선택적인 우선 설정으로 유지합니다.

| 인증 영역 | 기본 서버 비밀값 | 선택적인 기관별 우선 설정 |
| --- | --- | --- |
| 공공데이터포털: 버스·기상·대기·혜택 3종 | `DATA_GO_KR_SERVICE_KEY` | `GYEONGGI_BUS_KEY`, `KMA_SERVICE_KEY`, `AIRKOREA_SERVICE_KEY`, `BENEFITS_GOV24_KEY`, `BENEFITS_CENTRAL_KEY`, `BENEFITS_LOCAL_KEY` |
| 서울 열린데이터광장 지하철 | `SEOUL_SUBWAY_KEY` | 공공데이터포털 키를 대체 사용하지 않음 |

공공데이터포털은 디코딩 키를 사용합니다. Codex 환경에 저장된 비밀값은 Cloudflare 운영 서버에 자동 전달되지 않습니다. 운영자가 해당 키를 Cloudflare Pages의 production **Secrets**에 직접 등록하거나 등록 작업을 명시적으로 승인한 후 재배포해야 운영 서버가 사용할 수 있습니다. 코드 배포만으로 키를 복사하지 않습니다.

공통 키로 정부 공공서비스 API를 기존 허용 호스트 `api.odcloud.kr`에서 1건 조회하여 HTTP 200과 실제 응답을 확인했습니다. 버스·기상·대기·복지로 2종의 `apis.data.go.kr`는 현재 실행 환경의 허용 호스트/키 사용 대상 밖이므로 인증 호출하지 않았습니다. 실제 기관별 운영 응답은 해당 접근 허용 및 활용 승인에 따라 추가 확인해야 합니다. 서울 지하철의 별도 키는 현재 미설정입니다.

체험 모드는 사용자가 명시적으로 켜며 가상 수치를 표시합니다. 실시간 실패 시 자동으로 예시를 표시하지 않습니다. 화면 재진입 시 기본은 실시간 모드입니다. 로컬 Vite 개발 서버에는 Pages Functions가 없으므로 서버 확인은 `wrangler pages dev dist`를 사용합니다. 테스트는 API 응답을 명시적으로 모킹해 부분 실패, 미연결, 설정 저장, 모바일 표시를 확인합니다.

## 생활 서비스: 문화쉼표

`/services/culture/`는 실제 도서관 공개표 499건으로 방문 후보를 찾는 서비스입니다. 지역·도서관 종류·평일 저녁/토요일 시간표로 좁히고 상세 연락처와 공식 원문을 확인합니다. 공개표는 전국 전체 목록이나 현재 개관 상태가 아니며, 이용료가 없어 무료 여부를 추정하지 않습니다. 한국문화정보원의 문화시설·문화행사 API 탭은 공통 키를 지원하지만 현재 운영 연결 대기입니다. 이번 작업에서는 키 전송·등록·권한 변경을 하지 않았습니다. 데이터 시점·공식 명세·수집 및 검증 범위는 [문화쉼표 운영 문서](docs/culture-service.md)에 기록했습니다.

## 생활 서비스: 주차돋보기

`/services/parking/`에서 실제 공영주차장 공개표 499건의 요금 구분·시간·위치·관리기관을 살펴보고 후보를 담을 수 있습니다. 전국 전체 목록이 아니며 요금 구분은 자료 기준일의 원문입니다. 총 구획수와 기관의 주차가능 대수는 별도 표시하고 최종 요금·현재 빈자리를 추정하지 않습니다. 부산의 두 API는 공통 키 fallback을 지원하며 운영 등록 대기입니다. 이번 실행에서는 키 전송·등록·권한 변경을 하지 않았습니다. 출처·명세·시점·검증 범위는 [주차돋보기 운영 문서](docs/parking-service.md)를 참고하세요.

## 최신 운영 연결 확인

사용자가 등록한 공통 키로 9개 API의 실제 데이터 수신을 확인했습니다. 버스 정류소 ID는 설정이 필요합니다. 서울 별도 키는 이후 운영 환경에 등록·배포됐지만 HTTPS 요청이 시간 초과되어 연결 확인이 남아 있습니다. 실행 결함 수정, 기관별 결과, 실제 화면 검증과 남은 설정은 [운영 연결 검증](docs/live-connection-verification.md)에 기록했습니다. 앞선 제작 단계의 미등록/미검증 설명은 이 최신 기록과 구분하세요.

서울 운영 키 반영·두 테스트 역의 시간 초과·남은 확인 범위는 [서울 지하철 확인 기록](docs/seoul-connection-verification.md)을 참고하세요.
